# 《朝朝如念》｜wuh.site 介绍片 v2 · 剧本

**一句话定位**：四分钟长编年——从 2021 年的旧站到 2026 年的现在，讲清 wuh.site 的实现历程与设计巧思，也讲清写它的人。

**规格**：正片 7658 帧 / 4:15.3 @30fps；FilmShell 片头 120 + 片尾 180 → 全片 7958 帧 / 4:25.3（约 4:25）。八幕（含空间层「入院」）；代码动效片，无真人出镜、无配音，文案即屏幕字幕。片头、片尾由家族套件承担，本剧本不写；姓名卡若由套件收尾，8-7 只作交接行。

**素材基准**：`materials.md` v1（2026-10-31 采集）。全片日期、数字、引语一律以该文件为准，不追新、不外推。

**贯穿意象**：墨点——站点时间轴上的那一滴。它从 2019 年落下，在 2025 年停住，2026 年重新洇开；「入院」把它收进屋里，逐一看清。

## 一、叙事轴：真实时间线对账

### 1.1 结构声明

本片**以严格编年为主体，外加题记层与空间层，不是情感蒙太奇**。带日期的事件全部按素材库 §一 的真实顺序推进，无倒叙、无交叉剪辑、无「先给结果再回望」：

> 2019 博客开篇（前史）→ 2020 第一代个人站（前史）→ 2021 旧站与第一次重构 → 2022–2024 → 2024-12-08 现任站点第一行代码 → 2025 沉默 → 2025-12 回暖 → 2026 春夏重启与上线 → 2026-06-21《重启计划》→ 入院（空间层）→ 2026-07 坐忘 → 2026-08 至 10-31 现在。

两层需要显式声明：

1. **题记层**：开篇 Hero 题记「wuh.site · 朝朝如念」先于时间线出现；结尾站点金句回环。题记本身没有日期，不属于任何时间事件。
2. **空间层**：第六幕「入院」在 2026-06-21《重启计划》钤印之后、2026-07 推窗之前，**不推进任何时间**——它是「走进自己盖好的房子」的一次巡礼。它使用 2026-10-31 的站点现况快照（46 篇文章、12,651 格活动、365 天热力图等），不按 6 月底计数；因为它是空间层而不是时间事件，所以不与编年冲突。

空间层不改变编年顺序：入院之后，推窗仍是七月，坐忘仍是 2026-07，此刻仍从 2026-08 开始。

第八幕的「衍生之树」是「现在」的横向展开：五根枝按出生时间排序（博客 → 工作流 → 桌面 → CLI → 视频工作室），不是倒叙，也不新增时间事件；它把那座站点长出来的生态收进同一张纸。

选择编年而非蒙太奇的理由：这段历史的力量来自「真实发生过」。2025 年的空洞不需要悬念包装，2024-12-08 的重音也不需要提前预告；把顺序交给时间本身，情绪由密度自然产生。空间层让设计被看见，但不把设计伪装成时间。

前史按用户拍板压缩为两笔、各一句：2019 博客开篇、2020 第一代个人站。其余事件（2020 年的第一次停笔、2021 年的 UI 设计稿等）不入正片字幕，只作画面背景；其中 2021-04 的设计稿已在 2-2 画面出现。
