## 一、概述

**基调——纸上的编年史。** 承接 v1「纸上电影」的材质语汇：暖白纸、暖黑场、朱红钤印、衬线年份；全片像一本被翻开的旧账本，数据、代码、诗文都长在纸上。全片**没有一次急推，唯一一次白闪**在 2026-06-14 上线（5-2），其余冲突全部交给明暗、景别与留白；除 5-2 外任何一帧都不得到达纯白。

**结构——编年 + 两层非时间段落。**（引自剧本§一、§二）带日期的事件严格按素材库§一顺序推进；两处例外显式声明：**题记层**（开篇「wuh.site · 朝朝如念」与收尾打字机句，本身没有日期）与**空间层**（第六幕「入院」位于 2026-06-21 钤印之后、七月推窗之前，不推进时间，使用 2026-10-31 站点现况快照——46 篇文章、12,651 格活动等；以暗色控制台的 4×2 八块交互完成巡礼）。

**节奏曲线——两起一坐，两段缓。**（引自剧本§三）强度 2 → 3 → 3（幕内 3→4）→ 1 → 4 → 3 → 3 → 5（收于 2）：2021–2024 缓慢起身，2025 长坐，2026 两次起身；第六幕「入院」是暖的缓——看房子，第七幕「坐忘」是深的缓——坐下来。第八幕先满（版本雨与播放器），再由 8-4 衍生树把「方法与作品」长成五枝，8-5 总结纸页收束、数字退成脚注。第一记重音 2520f、唯一白闪 4000f，均不提前预告。

**视觉总则。** 墨点贯穿——2019 年落下（S1）、2025 年停在四步（S23 / S24）、入院时铺成 46 枚（S35）、2026 年重新洇开（S56 / S57 与开篇同形同位）。数据可视化一律「纸面化」：纸柱、暖色热力格、光点版本雨、纸页榜单、墨线衍生树；禁止纯科技蓝发光 UI。唯一例外是第六幕「入院」的暗色控制台外壳（细线网格 / 等宽标签 / 扫描线 / 朱红暖金高亮），但展开窗口内仍然是纸面内容。第八幕 8-4 用墨线与纸卡长出一棵五枝的树，8-5 把全片母题叠印回同一张纸，数字退成脚注。字幕是唯一黑体；年份、引语、题记用衬线；代码、数字、坐标用等宽。

**音乐。** 90 BPM，1 拍 = 20 帧；v1 冻结无 SFX，所有「落、点、闪」的听感由音乐与画面承担。
