## 三、站点架构与技术栈 [源码 README / package.json]

- **monorepo**：`apps/site`（Next.js **16.3.2** · React **19.2.5** · TypeScript 5 · styled-components 6）· `apps/server`（NestJS 10 · MongoDB/Mongoose 8 · REST `/v2` + Swagger）· `apps/console`（Vite 管理端）· `packages/components`（共享组件库 + CSS 变量主题令牌）
- **写作即提 Issue**：GitHub Issues 作为 CMS——`stack-wuh/blog` Issues → sync + webhook → MongoDB → 前端消费统一 API
- **功能**：博客（Shiki 高亮、章节眉线、首字下沉）· 话题聚合 `#label` · 弹幕留言板（虚拟滚动）· 足迹地图 · 关于页（GitHub 资料 + 热力图 + 足迹）· 音乐（自建网易云 API + 降级）· 设计系统（亮暗双模式）· SEO（JSON-LD / sitemap / RSS）
- **部署**：Docker + CI/CD（CodeQL、prepare-deps 共享、30m 构建超时、磁盘守卫、每日清理、release 脚本、构建迁移 runner + SSH 镜像上车）
