# 《风陵 · 致郭襄》｜四分钟武侠诗电影 · 剧本

**一句话定位**：以网络流传、托名程灵素的六行诗为骨架，讲一个女子如何把十六岁那夜别人给她的光，用了二十四年，认成自己的天色。

**规格**：正片 7200 帧 / 4:00 @30fps；FilmShell 片头 120 + 片尾 180 → 全片 7500 帧 / 4:10。六幕。代码动效片，无真人出镜、无配音、无 SFX；字幕即文案。片头、片尾由家族套件承担，本剧本只写正片；帧区间一律 0 基、左闭右开。

**素材基准**：`materials.md` v1（2026-11-01 采集）。诗作以 §1.3 定稿文本为唯一源（INV-5）；原著事实以 §1.1 年表为准；不引原著大段正文。

**贯穿意象**：两次「亮」——十六岁的烟花与峨眉的云霞，同一组暖金。第一次是别人给她的，第二次是她自己看见的。其余全是纸、墨、雪、青灰。

## 一、叙事轴：三重时空与记忆顺序

### 1.1 结构声明

本片是**情感蒙太奇，不是编年**。

四条线：

- **甲 · 十六岁**：风陵渡听传说、得三枚金针 → 九月廿四生辰，满城烟花 → 华山别（约十七岁）。
- **乙 · 寻人**：华山别后三年起，骑青驴遍访江湖，至少林（约十九至二十岁）。
- **丙 · 出家**：约三十岁于襄阳城破前得倚天剑 → 四十岁在峨眉出家、立派。
- **画框 · 晚年**：第一人称回望。不占时间线，只开合全片。

正片顺序：**画框 → 甲 → 甲 → 乙（出口接丙） → 丙（内插丙的前史） → 画框**。

不做编年的理由：按编年讲，观众会顺理成章地看到「她遇见他、他离开、她寻找、她出家」——因果清楚，也因果伤人。那正是世人的版本。要翻案，就不能用因果的顺序讲。所以本片按**记忆的重量**排序，不按**事件的时间**排序：先给她晚年的一句话（我在走），再给全片最亮的一夜，再把世人的说法完整说完，最后才让她自己说。时间服从记忆，不服从日历。

### 1.2 时间跳跃点（四处）

| # | 跳跃 | 从 | 到 | 处理 |
|---|---|---|---|---|
| J1 | 幕三末 → 幕四 | 华山之巅，约十七岁 | 青驴江湖，约二十岁 | 以驴蹄四拍入，不做字幕交代时间 |
| J2 | 幕四末 → 幕五 | 四十岁上山 | 同一段逐帧重放 | 不跳：时间在此不打结，只换解释 |
| J3 | 幕五 5-2 → 5-3 | 四十岁门内 | 约三十岁，城破前后 | 全片唯一倒叙插入；雪白与火光对峨眉金，画面自证 |
| J4 | 幕六 6-2 → 6-3 | 峨眉山门 | 弟子抬头所见的天空 | 以视线交接，不做转场特效 |

J3 是唯一需要观众主动辨认的时间弯折。它插在「越点」之后、「缰绳与经卷」之前：先把剑的来历交代清楚，再让她把缰绳放下——顺序不能反。

### 1.3 人称的三段

全片只有三个人称阶段，不是渐变，是两记切换：

- **幕一**：**我**。晚年画框，诗第 1–2 行。
- **幕二至幕四**：**她**。传闻接管；字幕只作第三人称转述，不讲心理，不给判断。
- **幕五第 4320 帧起**：**我**回来，此后不再离开（诗第 5–6 行）。

中段被拿走的那个「我」，就是被传闻盖住的那个人。4320 帧一个字切回来——不是解释，是认领。

补记：诗第 4 行「大家都说我因为爱着杨过大侠」里的「我」，是**世人判词里的「我」**——它被「大家都说」引用，属于台词，不属于叙述人称。「幕二至幕四用第三人称」说的是叙述者，不是被引用的诗行；两者不冲突，诗不改一字。

| 六 | 像极了 | 峨眉晚年 | 6000–7200 | 1200 | 16.7% | 5→2 | 两片金贴在同一帧上 |

合：720 + 900 + 1500 + 960 + 1920 + 1200 = **7200**；加 FilmShell 120 + 180 = **7500 帧 / 4:10**。

晚年回望不单独成幕，它是画框：幕一开，幕六合。

幕五是全片最长的一幕（26.7%）。翻案之后必须让她真的活一遍，不能一句「出家」带过；这一幕是她自己的版本，也是唯一一幕按「日子」而不是按「事件」推进的。

诗六行只落在幕一、幕四、幕五、幕六。幕二、幕三无诗——记忆不配旁白。

### 2.2 重讲结构：三处翻案

#### 翻案一｜原帧重放 + 越过断点（结构）

| 项 | 帧 | 说明 |
|---|---|---|
| 原镜 4-4 | 3840–4080（240f） | 白衣上山；第 4 行 3860–4060；4060–4080 山门开一线，将暗未暗 |
| 重放 5-1 | 4080–4320（240f） | 与 3840–4080 **逐帧一一对应**；不改色、不倒带、不换机位、不换景深、不落字幕 |
| 断点 | **4320** | 重放末帧＝原镜末帧。世人的版本在这里结束 |
| 越点 5-2 | 4320 起 | 不切、不暗；门继续开，光扩出来 |
| 人称切换 | **4320** | 诗第 5 行「其」字与断点**同帧**；第三人称 → 第一人称 |
| 第 5 行 | 4320–4500（180f） | 4500–4560 定格呼吸 |

第一版把「山门开一线」当作句号，第二版把同一帧当作逗号。不是改写，是接着往下活。世人的版本停在门口，她的版本从门口开始。

#### 翻案二｜判词消失（字幕）

重放时不再落第 4 行。画面一帧没变，变的是**压在画面上的那句话**——它被拿掉了。观众第二次看见的不是新镜头，是自己的误读。

#### 翻案三｜剑的来历（物）

幕四 4-1，剑挂在驴背上，剑穗垂着。上一幕刚是华山别，观众自然把它读成他留下的信物。幕五 5-3，雪与火光里剑从雪中被拔出，剑鞘有火燎痕；5-6 它挂上墙，再没取下来。它其实是父母在城破前铸的，是襄阳的重量。

三处翻案，字幕一处都不解释。

## 八、自查

### 8.1 帧数

- 六幕：720 + 900 + 1500 + 960 + 1920 + 1200 = **7200**。
- FilmShell：片头 120 + 片尾 180 → 全片 **7500 帧 = 4:10 @30fps**。
- 占比：10.0 + 12.5 + 20.8 + 13.3 + 26.7 + 16.7 = 100.0%（四舍五入，帧数为准）。

### 8.2 重讲对账

- 原镜 4-4 为 3840–4080；重放 5-1 为 4080–4320，帧数相等、逐帧对应。
- 断点 4320 同时是：重放末帧、门开一线那一帧、诗第 5 行「其」字起笔帧、第三人称转第一人称帧。四件事同帧，是本片的结构签名。
- 重放段不落第 4 行；第 4 行只在 4-4 出现一次。

### 8.3 硬约束核对

- 诗六行逐字对照 §1.3，未改一字；标点（第 1/2/4/5 行句末逗号、第 3/6 行句号）原样保留。
- 「峨嵋」仅出现在诗第 4、5 行；其余全部「峨眉」。
- 正片 1-1（0–180）为纯画面，无片名、无题记、无托名说明；片名与题记只在家族片头出现一次（`meta.title` / `meta.episode`）。
- 幕三字幕仍为 2 条（#5、#6）；「全城无人记得她的生日」只由画面承担，未新增解释性文案。
- 十六岁段（幕二、幕三）不出现倚天剑；剑首次入画在幕四 4-1。
- 杨过无正脸、无台词、无正面转身；仅背影（3-4）与他人转述（2-2）。
- 无「如果当初」「等了一辈子」「为他出家」类表述；出家写作主动选择（5-2 越点、5-4 抬眼、5-5 教人）。
- 无配音、无 SFX；第 3 行「滴滴答答」由驴蹄画面节拍承担，不进音轨。
- 襄阳城破虚写：只有雪、火光、断墙、剑，无屠杀、无血、无人。

### 8.4 已知取舍

1. **幕四 4-1 剑随驴行**：诗中「倚天剑伴我走天涯」与原著「约三十岁才得剑」有年表差。本片按晚年回望口吻处理，剑先在驴背上出现（诗的字面），再在 5-3 揭示来历（事实）。两处不冲突，但要求分镜在 4-1 只给剑的形，不给剑的来历。
2. **5-3 是全片唯一倒叙**：以雪白/火光对峨眉暖金，画面自证时间不同；不靠字幕交代。
3. **三件生日礼物只留烟花一件**：礼 1、礼 3 不进片。理由是逐件交代会把四分钟变成事件清单，也会把杨过变成男主角。
4. **铁罗汉不解释**：懂的人会懂；不懂的人也不损失。
5. **风陵师太在幕六 6-2、第 6 行之前**：先落法号，再落诗，收黑顺序不可调换。
6. **片名与题记移交家族片头**：正片因此从头到尾没有一处文字告诉观众片名或托名。托名的重量由套件的 `meta.episode` 承担，正片不重复——重复一次，题记就轻一分。
