## 一、概述

### 1.1 基调：纸上的回望

本片与 intro-v2 同一套纸墨语汇，但更冷、更空。暖纸白 `#f5f0e8` 与暖黑 `#0f0e0c` 之间，全片只放三种东西：墨、雪、光。

全片只有两次「亮」：十六岁的烟花（幕三 3-2）与峨眉的云霞（幕六 6-1～6-4），同一组暖金。第一次从下往上打光——她抬头，光落进眼睛；第二次从平处铺开——她平视，光就是天。第一次是别人给她的，第二次是她自己看见的。其余时间全是纸、墨、雪、青灰。

正片不含朱红：剑穗用纸灰（paperMuted），金针身用 paperMuted，灯与火都不许红。全片唯一的红留在家族片头那枚印上；正片唯一的暖色，就是那两片金。

### 1.2 结构：六幕与一个断点

幕界 0 / 720 / 1620 / 3120 / 4080 / 6000 / 7200，全部落在 20f 节拍网格上。

重讲的物理落点只有一个：**4320**。原镜 4-4 ＝ S30（3840–4080，240f，一镜到底）；重放 5-1 ＝ S31（4080–4320，240f），画面、机位、景深、帧数逐帧一致，唯一的不同是撤掉诗第 4 行。4320 同时是：重放末帧、门开一线那一帧、诗第 5 行「其」字起笔帧、S32 的起帧。四件事同帧——所以 4-4 与 5-1 各自必须是一镜，不许拆成多镜，否则逐帧对应无从谈起。

同理，4-1 的驴与剑必须是一镜到底（S25，240f）：「滴滴答答」四字各 12f，与驴蹄四次起落同帧，是全片唯一逐字对拍的段落。

### 1.3 视觉总则

- **材质**：纸纹全程可见（噪点 ≤8%）；暗场不用纯黑，亮场不到纯白。
- **人的规矩**（按 `character-design.md` 四级制）：全片无正脸、无双眼、无嘴、无鼻梁高光。默认 L0（背影、剪影、只手）；L1 只给后脑、颈、肩、下颌线；L2 侧脸一条线（额—鼻—唇—颌）、无眼无嘴，仅 2 镜；L3 只有一点反光、无眼白无瞳孔，全片 3 次各 ≤100f——S8 火塘 1140–1240、S18 烟花 2220–2320、S38 佛前灯 5100–5160。逐镜面级见 §五。
- **时间**：不靠脸，靠三样东西编码——头身比、发式、衣色；6.5 → 6.8 → 7.0 → 7.0 → 6.2，双环髻 → 单髻 → 落发 → 白发。
- **剑的规矩**：十六岁无剑（幕二、幕三不出现任何剑形）；4-1 首次入画，只给形、不给来历；5-3 揭示来历；5-6 挂上墙，再没取下来。
- **三次「无声的响」**：驴蹄（S25）＝四字四拍；门开（S30 / S31）＝一线光；剑出雪（S35）＝一小片雪。全片无 SFX，这三下都由画面承担。
- **重讲不解释**：三处翻案（原帧重放、判词消失、剑的来历）字幕一处都不解释。

### 1.4 节奏

- 节拍网格沿用品牌 90 BPM（1 拍 ＝ 20f），仅作卡点参考：不选曲、不定音轨。
- 全片无 SFX，音效列一律「无 SFX」；音乐点只标「第几拍、落在哪个动作上」。
- 强度（剧本 §2.3）：2 → 3 → 5 → 3 → 4 → 5（收于 2）。幕三是唯一的响，幕四是唯一的谷，幕五是唯一按「日子」推进的一幕，幕六是最慢的一幕。
- 长镜全部落在「不说话」的地方：山、海、驴、上山、重放（各 240f）。短镜全部落在转折：搁笔、余烬、离渡、定格、空钉（各 60f）。

### 1.5 人物

郭襄五段：十六岁（S6–S12，双环髻 + 雪青 + 风帽）、约二十岁（S25、S27，单髻 + 布巾 + 褪色雪青 + 绑腿）、四十岁上山（S30–S32，单层白袍 + 单髻 + 空手）、出家后（S38–S44，落发 + 缁衣 + 内领一线雪青）、晚年（S4，只给右手）；约三十岁只在 S35 给一只手（护腕）。杨过只有背影与空袖（S22–S23），无正脸、无台词、不带剑。风陵师太与十六岁的她同一条剪影 path（×0.93）。具体形制见 §五。
