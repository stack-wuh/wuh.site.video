## 一、设计总纲

**一句话画法：人如墨影，物如刀刻；全身是剪影，手是第二张脸。**

| 层 | 画法 | 线的语言 | 禁止 |
|---|---|---|---|
| 人 | 单色填充剪影（`colors.ink` 或 `colors.paper`），内部至多 2 条 1.2px 结构线 | 轮廓即造型，粗细不变 | 不画肌肉、衣纹细节、五官写实 |
| 物 | 2px 主轮廓 + 平涂，局部 3px 承重线 | 线要「断」，不追求闭合 | 不做体积光、材质贴图、金属高光 |
| 景 | 0.8px 远线、平涂、留白；雾用 1–3 条横线 | 线越远越淡 | 不做写实透视、体积雾、晕染 |

**面部最小化（四级制，全片可数）**

| 级 | 定义 | 允许处 | 配额 |
|---|---|---|---|
| L0 | 无面：背影、剪影、只出一只手 | 全片默认 | 不限 |
| L1 | 只给轮廓：后脑、颈、肩、下颌线，线内无五官 | 2-1、2-4、3-1、3-4、5-5 | — |
| L2 | 侧脸一条线（额—鼻—唇—颌），无眼无嘴 | 3-3 仰脸余照；6-2 风陵 | 2 镜 |
| L3 | 眼：只有一点反光，无眼白、无瞳孔、无目光 | 2-2 火塘、3-2 烟花、5-4 佛前灯 | **全片 3 次，各 ≤100f** |

1. 全片无正脸、无双眼、无嘴、无鼻梁高光；鼻子只在侧脸轮廓上存在。2. 三次眼，三次光：火塘（听来的火）、烟花（别人放的火）、佛前灯（她自己点的灯）；每次只给眼与颧骨一角，脸的中轴不入画。3. 所有「肉」= `colors.paper` 填充 + `colors.ink` 1.2px 轮廓；不设肤色、不做明暗、不做红晕。4. 人物剪影内部结构线不超过 2 条（肩线 + 一道衣褶）；多一条，人就老十岁。

时间不靠脸，靠三样东西编码：**头身比、发式、衣色**。6.5 → 6.8 → 7.0 → 7.0 → 6.2；双环髻 → 单髻 → 落发 → 白发。观众记住的不是她的脸，是她走路的样子。

### 2.3 上山背影 · 标准姿态（4-4 / 5-1 逐帧重放）

**实现前提**：两镜挂同一个组件 `<AscendBack f={0–239} />`（local = 全局帧 − 3840 或 − 4080），props 全等，调色层、雾层、门缝层为共享层。验收：4-4 第 239 帧与 5-1 第 239 帧像素差分为 0。

| 项 | 规格（viewBox 1920×1080） |
|---|---|
| 机位 | 固定；无推拉摇移；山门灭点 (960, 238)；石阶下缘 x∈[576, 1344] |
| 剪影 | 身高 300px → 276px（f239，scale 0.92，越走越小）；头高 43px（7.0 头身）；肩宽 72px；衣摆最宽 102px |
| 位置 | f0 脚底 y=929；f239 脚底 y=670；总位移 259px，`CV-01` 缓出（非匀速） |
| 朝向 | 正背；脊柱中线 x=884 恒定 ±0；上背前倾 2°（四十岁），肩线水平；不侧身、不回头、不加头部微转 |
| 负重 | **空手**；无伞、无剑、无包袱；两臂垂于体侧，袖口离手 26px |
| 衣摆 | 白袍离阶 20px，永不拖地；后摆横摆 ±8px，相位 = 步相 |
| 发梢 | 单髻 + 发带 60px + 衣带 90px；滞后步相 6f，摆幅 ±4px |
| 步频 | 40f/一步；0–199 五步；200–239 立定 |
| 门缝 | 1px 居中；200–239 由 1px 开至 6px；缝内一线 paper 光落在阶上（宽 ≤6px），**不扩散**——大光从 5-2 的 4320f 才出来 |

步法：0–199 走五步，40f/步，首步右脚，承重脚右→左→右→左→右；200–239 立定。衣摆随步做三角波 +8→−8→+8，垂带滞后 6f、摆幅 ±4px。

**为什么空手**：伞会把「出家」读成「避雨」，剑会把「放下」读成「携带」。她一步一步走上去，手里什么都没有——这是 5-6「剑挂在墙上，再没取下来」唯一的伏笔。

**负形**：白袍不作 mask，作「后画」——山体先落 `colors.ink`，人物以 `colors.paper` 填形压在其上，1.2px `colors.ink` 收口。白袍是墨里挖出的一个洞。

## 三、杨过

**只给背影、剪影、空袖；全片没有正脸、侧脸、下颌线、眼。** 他一露脸就变成男主角，片子就变成爱情片。

| 项 | 规格 | 作用 |
|---|---|---|
| 出场 | 仅 3-4（2700–3120），一次；其余全在别人口里（2-2） | 他不是人物，是传闻 |
| 身高 | 真人高 1.2× 郭襄；同画时剪影 300px（depth 0.85，2.4px 模糊等效） | 高半头，不并肩 |
| 断臂 | 右臂断于肩下；空袖长 60px、宽 22px，钉在肩点，摆动 ±8px | 唯一的身份证明 |
| 衣袍 | 深墨长袍（`colors.ink` 填充）；左袖宽 44px，右侧无袖 | 一袖宽、一袖空 |
| 发式 | 长发半束，无冠、无簪、无玉；发长过肩 40px，两缕 | 不富贵、不江湖 |
| 手 | 左手为空（储备：只许拨雾、扶石）；**右手永不出现** | 手是留白 |
| 剑 | **不带剑**。玄铁重剑已赠出；**他从不持倚天剑** | 剑不属于他 |
| 面部 | 无。连后颈线都藏在发里，只留肩线与后脑一弧 | 传说没有脸 |

**华山转身 · 标准姿态（3-4，local 0–420）**

| local 帧 | 动作 |
|---|---|
| 0–119 | 背立右侧三分之一，不动；云在脚下翻 |
| 120–143 | 肩先动：上身转 0→14°，头不转；空袖前摆 12px |
| 144–179 | 三步入雾，12f/步；步幅收窄，衣摆不摆 |
| 180–299 | 雾合：opacity 1→0.15，轮廓先散，肩线最后消失 |
| 300–419 | 只余 0.8px 肩线，320f 起全无；她仍在左侧原地 |

字幕 3000–3080（local 300–380）恰好落在他消失之后——「他没有回头」，画面也不给他回头。

## 六、线与色

### 6.1 线宽五级（viewBox 单位，随镜头缩放，不开 `non-scaling-stroke`）

S0 = 0.8px（远山、雾、水纹、针身、冰凌）；S1 = 1.2px（发丝、衣褶、缰、剑穗、眉、眼睑）；S2 = 2.0px（器物主轮廓：驴、船、经卷、铁罗汉、剑身、门梁）；S3 = 3.0px（承重与断点：门柱、剑格、断墙）；F = 填充无描边（人物剪影、山体、门扇）。

### 6.2 色（只用 `brand/tokens` 与影片私有色；场景内禁十六进制、rgba、hsl 字面量）

| 令牌 | 来源 | 只用于 | 不用于 |
|---|---|---|---|
| `colors.ink` | brand | 剪影填充、线、夜 | 大面积底 |
| `colors.paper` | brand | 「肉」、白袍、雪、纸 | 纯白高光 |
| `colors.paperMuted` / `paperDeep` | brand | 次级纸、衣、经卷、剑穗 | 主轮廓 |
| `colors.accent` | brand | 土黄渡口、烛、铁罗汉磨亮、衣摆尘 | 皮肤 |
| `colors.gold` | brand | 金针、云边、光尘 | 大面积 |
| `colors.seal` | brand | **只有印** | 其余一切 |
| `colors.muted` / `bg` / `bgLift` | brand | 远雾线、夜底、暗场 | 人物、日景 |
| `FILM.snowCyan` | 影片私有 | 郭襄衣、青驴边光、石青 | 天光 |
| `FILM.nightBlue` | 影片私有 | 3-2 夜空、雪夜 | 人物 |
| `FILM.fireGold` | 影片私有 | 两次「亮」（烟花、云霞）＋佛前灯局部 ≤80px | 金针、印、大面积夜 |

三枚私有色在 Phase 4 的 `videos/preprod-zhi-guo-xiang/motion-tokens.ts` 声明一次，只声明一次。人物身上最多两种颜色（一填一收口），第三色即弃。

### 6.3 剪影对比

纸白底 → ink 实心；墨山 → paper 负形 + ink 1.2px 收口；夜 → ink + `fireGold` 1.2px 边光（只给下颌、肩）；雪 → 无人，只有一把 ink 的剑；暖金 → ink 剪影 + gold 1px 侧光。明度差 ≥70%，边光 ≤1.2px，人物永远不做 glow / bloom / 描边发光。

### 6.4 Remotion / CSS / SVG 落地

- 人物 = 一个闭合 `<path>`（锚点 ≤24，只用 C/Q），`fill` 单色、`stroke="none"`；结构线独立 `<path>`，`opacity ≤0.35`。
- 位移只用 `transform`；摆动用 `Math.sin(frame / 40 * 2π)`；禁 `width / height / top / left` 动画。
- 4-4 / 5-1 共享同一 path 常量与同一 local 帧；人物禁 `random()`；雾与光尘用 `random(seed)`，两镜同 seed。
- **禁全屏 `radial-gradient`**（playbook：动画径向渐变 + screen/soft-light 在本机 Chrome 确定性崩溃）。暗角、晨光用四边 `linear-gradient` 或 `clipPath`；样片级半透明渐变一律改 2–3 帧硬切。
- 局部 radial 只允许三处：佛前灯 ≤80px、金针尖 ≤4px、印章朱晕 ≤240px；禁 `<Audio>`，禁水墨晕染（不做 `feTurbulence`、不做位移噪声、不做墨迹扩散）。

## 九、与分镜 / 动效的接口

### 9.1 裁决顺序

剧本定稿与用户拍板 → 本文硬约束（不露脸、16 无剑、空手上山、只给三次眼）→ 分镜构图与镜头语言 → 动效偏好。冲突时降级的是后两者；若第一条要改，先改剧本，再回填本文，不在分镜里私改。

### 9.2 一致性 vs 叙事

允许随镜头变的只有三样：**光、雾与遮挡、景别尺度**。剪影 path 不变。需要「新状态」（如 30 岁全身、华山雪中的她）时，先在本文件加一行规格，再让分镜画——顺序不能反。
