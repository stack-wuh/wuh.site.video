## 四、实现口径（正式制作 change）

- 成片 / animatic 保持无声；CI 只出画面；正式发布前在本地 mux。
- 本地 mux 命令（示意；`<film-silent>` 与 `<aiyi.mp3>` 为本地路径）：

```bash
ffmpeg -y -i out/<film-silent>.mp4 -i "<aiyi.mp3>" \
  -filter_complex "[1:a]atrim=0:139.46,asetpts=PTS-STARTPTS,afade=t=in:st=0:d=1[a1];[1:a]atrim=0:102,asetpts=PTS-STARTPTS,afade=t=in:st=0:d=1,afade=t=out:st=99:d=3[a2];[a1]adelay=4000|4000[d1];[a2]adelay=148000|148000[d2];[d1][d2]amix=inputs=2:duration=longest:dropout_transition=0:normalize=0,volume=0.7[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k -shortest out/<film>-aiyi.mp4
```

- `volume=0.7`（约 -3 dB）留给 AAC 编码与 B 站二压余量；本次试听版用 `0.89`（约 -1 dB）。
