# v3 出片验收门（2026-11-11 立门：用户判词「为什么问题全靠我跳出来」）

> 出发点：这是给 wuh.site 做的年度数据叙事片——**每一帧都要向观众展示站点的真实家底**（写的文、读的书、听的歌、跑的流量、打的版本），数据当主角，大胆呈现。技术正确（帧数/音画/typecheck）只是及格线，**意图达成才是验收线**。出片前逐镜过本门，任何一条不过即返工，不带上门交付。

## 门 1 · 数据直读零快照

- `staticFile('wuh-site-intro-v3/site/…')` / `<Img>` / 封面图 / 裁切图：**代码零引用**（注释提及也算未清干净）。
- 每个被展示的对象必须能说出它的数据源文件（books.ts / YEAR_FAVS / heatCells() / DATA / 真实文章数据）。

## 门 2 · 内容覆盖表（家底七类各有主场镜）

提交史 / 文章（46 篇+真实阅读数）/ 书架（146 本真数据）/ 音乐（八年真歌单）/ 流量（13,603+365 格+1,842 阅读）/ 版本（118+v7.4.0+266 归档）/ 知识树（40 卡+衍生树）。任何一类只被「一句字幕带过」而无主场镜 = 不过。

## 门 3 · 编排四问（每镜头注释必答）

承接什么 / 谁触发什么动作 / 帧级节奏数组怎么展开 / 尾帧交什么。镜内事件 ≥4 拍；连续静止 ≤12f；数据入场必有位移或形变，禁原地淡入。

## 门 4 · 版面零事故

- 镜内文字（含脚注/数据件）**絕不进 Caption 安全区**（bottom 150px 内禁排镜内文字）。
- 一切文本行宽 ≤85% 画面宽；句尾距纸缘/屏缘 ≥60px。
- 同一句文本镜内与字幕不同位重叠（可分屏呈现，不可叠印）。

## 门 5 · 意义一句话

每镜能用一句话回答「观众在这一镜看到/感受到什么」。答不出 = 镜无存在意义，砍掉或重做。

## 门 6 · 出片前机器+肉眼双检

- 机器：typecheck 零错、零截图 grep、动效节拍 ≥4 扫描、底部文字风险扫描。
- 肉眼：全片渲染后**每镜抽中段帧+交接帧**，按门 1–5 过一遍（visual-judge），红单返完才交付用户。
