## 9. 编排范式 = 每镜一场戏（2026-11-11 用户判词「内容编排不如 v2」的修正令）

v2 的镜是事件链，v3 此前是海报。**每镜必答四问，缺一问返工：**

1. **承接**：首帧态 = 上一镜尾帧交出的东西（交接物入画、延续或回应）。
2. **触发**：本镜的主动作是什么、由谁执行（光标点击 / 印章落下 / 数据针扫过 / 翻牌）？——每镜至少一个「动作」，禁止纯静态排版 + 淡入。
3. **展开**：内容分层数据表演，节奏用**帧级数组**（`staggerLand` 生成 LAND 表；翻牌用 STEP 表）；多点落下前疏后密（accel），末点对音。
4. **交接**：尾帧态 = 交什么给下一镜（manifest `endFrameDesc` 是契约，视觉强化其语义）。

编排参考原件：v2 `shots/s22.tsx`（七点加速落纸+弧线回轴）、`shots/s38.tsx`（光标点开→唱针→八年翻牌→唱针抬起交接）。翻牌数据（八年年度最爱歌单）是真实数据，从 v2 s38 原样搬运。

## 10. 特效解禁（同日用户令「不再限制动效权利」——强度上不封顶，色板仍是唯一法源）

- **弹性**：入场一律 `springIn`（真 spring 过冲），禁裸 linear/单调 easeIn 淡入当主角。
- **冲击**：落定瞬间 = `shockwave` 双环 + `sparkBurst` 粒子（全 random(seed) 确定性）+ 辉光脉冲；SLAM 级落定（大数字/印章）必配。
- **逐字 kinetic**：金句/题名用 `kineticChars` 逐字弹入（step 2–4f/字），禁整段一次淡入。
- **光**：`sheenSweep` 金光横扫大数字/金句；`glowText` 落定脉冲保留。
- **纵深**：多层元素用 `parallax3` 三层视差；背景氛围可加 `dataCurtain` 数据雨帘（峰值 opacity ≤0.22，永远在信息层之下）。
- **拖尾**：快速位移元素（光标、流星、飞入卡）叠 `@remotion/motion-blur` Trail（已装 4.0.538）。
- **光标演员**：过程镜/翻牌镜入画执行主动作（琥珀光点 + 移动 + 点击 ripple），复用 FN-41 `inkCursor` 语义。
- 色板纪律不变：一切特效色取 FILM_COLORS2；三镜型配方、内容本体化（§3）、时间轴铁律、家族边界照旧。
- **「最大胆」基准**（同日用户令「用最大胆的展示动效展示数据」）：每个数据落定都有冲击（环/粒子/光扫至少其一）；连续静止不得超过 12f（呼吸微动不算静止）；数据入场必须有位移或形变，禁原地淡入。
