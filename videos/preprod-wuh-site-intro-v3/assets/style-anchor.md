# wuh.site 介绍片 v3 重做 · 风格锚点 v2 —— 亮色信息密度 · 纸上年报（2026-11-14）

> 状态：Lead 草案（待用户随剧本一并过目）。本文件是全片视觉宪法；镜级契约查技能 `shot-spec.md`，实现基元查 `remotion-capabilities.md`。
> 一句话：**浅纸为底，墨字为大，朱红点睛，数据当主角**——像一份印在好纸上的年度报告，被逐页翻开、逐数滚动。

## 0. 家族边界

- 片头（FilmShell BrandIntro 150f）与片尾（BrandOutro 180f）沿用家族套件，不参与本片风格重构。
- 正片 5700f 全部按本宪法执行；转场遮罩属转场层、非镜内容。

## 1. 色板（唯一合法色源 = `FILM_COLORS`，禁内联色值）

**与站点同源**：全部取自 x.wuh.site `wine` 亮色主题令牌（2026-11-14 线上实测值，出处 `.tmp/site-design-facts.md` §1.2）。片子与站点用同一套纸/墨/朱/金，观众看完片再打开站点，是同一个世界。

| 令牌 | 值 | 站点源 | 用途 |
|---|---|---|---|
| `paper` | `#F5F0EC` | `background-900` | 主画布（暖纸底） |
| `paperDeep` | `#EBE2D8` | `background-300` | 次级面 / 图表底 / 遮罩 |
| `card` | `#FFFBF8` | `background-100` | 卡片、终端、图表窗 |
| `ink` | `#2A1E16` | `normal-900`（站点正文墨） | 主文字 / 主数据（对纸 14.32:1） |
| `inkSoft` | `#5A4438` | `normal-800` | 次级文字（密集小字用这个，不用 muted） |
| `muted` | `#8A6E5C` | `normal-700` | 三级文字 / 标签 / 轴（4.16:1，只做非正文） |
| `hairline` | `rgba(42,30,22,0.14)` | 派生 | 1px 分隔线 / 网格 / 轴 |
| `vermillion` | `#C94A44` | `primary-500`（站点主色） | 唯一强调：重点数字、落定、冠军、印章描边（对纸 4.08:1，只给大字/图形） |
| `seal` | `#8A2A26` | `primary-700` | 印章本体 / 深朱压印 |
| `accent` | `#E3B567` | `--accent-color` 泥金 | 装饰与热力阶（1.68:1，**禁作文字**） |
| `amber` | `#C89060` | plain `primary-600` | 音乐 / 时间轴暖光 |

**纪律**：
- 全片只有三个色相：墨（黑褐）、朱（红）、金（橙黄）。分类图表用**墨色灰阶**（ink / inkSoft / muted / hairline 五档）承载多系列，**朱红只给「最重要的那一个」**——不平均、不撒点。
- 热力图沿用站点暖金阶：`paperDeep → accent 30% → accent 55% → accent 75% → accent`；**峰值只加朱红描边，不改填充**（站点同源语汇）。
- 禁蓝青紫、禁霓虹、禁彩虹渐变；渐变只允许同色相明度过渡（纸→纸深、墨→墨软）。
- 纯黑与纯白都不做大面积底：底永远是纸或纸深，纯白只作卡片与数据窗；**全片只允许一次纯朱红满屏**（三幕上线那 3f）。
- 小字纪律（对比度实测）：泥金禁作文字；朱红只用于 ≥19px 粗体或图形；12–15px 密集文字一律 `ink` 或 `inkSoft`。

## 2. 字体与字阶

**与站点同源**（`.tmp/site-design-facts.md` §1.7）：

| 层 | 字体 | 用法 |
|---|---|---|
| 大标题 / 大数字 | Noto Serif SC 700（衬线） | 片名、幕题、**巨型数字**（1,243 / 64,985 / 26,948）、年份水印 |
| 叙事句 / 引语 / 正文 | Noto Serif SC 400 | 动能字幕句、金句、榜行标题 |
| 数据标签 / UI | Noto Sans SC 400 | 标签、图例、角标、说明（**站点 Sans 700 未真正声明、body 禁合成粗体——本片不依赖 Sans 粗体**） |
| 代码 / 编号 | JetBrains Mono 400（站点同款；缺字回退 Menlo/Noto Sans Mono CJK） | 代码、commit hash、英文数据标签、四角角标 |
| 手写签名 | Ma Shan Zheng | 只在印章旁的手写「wuh.site」 |

字阶（1920×1080，8px 基线）：
- 巨型数字 200–280px（serif 700，字距 -2%）；单位/标签 22px mono 大写字距 0.18em
- 幕题 96–120px（serif 700）；引语 64–80px（serif 400，行高 1.35）
- 叙事句 44–56px（serif 400）；数据标题 34–40px（serif 700）；榜行 24–28px（serif）
- 角标 13–14px mono，字距 0.16em，`muted`
- 章节眉线（站点同款）：12px serif / 字距 0.42em / 朱红，如「第 04 节 · 屋里」
- **数字一律真数字形（lining figures），不用等宽数字表**；大数字与标签分置（数字主、标签小、下方一条 hairline）

## 3. 版式网格与角标

- 12 列网格，左右留白 120px，列缝 24px；内容区 1680px。
- 四角常驻角标（mono 13px，`muted`，不抢主体）：左上 `WUH.SITE`；右上 `2019 → 2026`；左下 `ACT 0X · 幕名`；右下 数据快照日 `2026-11-14`（第四幕起改 `LIVE DATA`）。
- 每个数据镜：**一个主数字/主图形 + 一条 hairline 基座 + 一枚小标签**，位置可换、语法不变。
- 留白纪律：单镜信息主体至少占画幅 1/3 的可读面积；**禁整屏空场**（唯一例外：二幕 2025 沉默段的一镜，且必须有「0」「4」这类反讽数字在场）。
- 画幅不倾斜、不加装饰性噪点纹理；纸感来自色，不来自贴图。

## 4. 三种镜型配方

- **数据镜（占比 ~55%）**：巨型数字/柱阵/折线/热力/榜单/环图。动作 = 滚动落定、生长、点亮、横扫；每镜 ≤2 个图形，宁少勿糊。
- **叙事镜（~30%）**：一句话 + 一个物。句子用动能排版逐字/逐行入画；物是数据件（一行代码、七个提交点、两枚地名、一条时间轴），**不是网站截图**。
- **方法镜（~15%）**：数据流图、CI 三节点、版本雨、仓库横条。线条与节点必须是真实关系（Issues → MongoDB → API → 前端），不许画装饰性「科技线框」。

## 5. 数据可视化语汇（每类给一条实现口径）

| 件 | 语汇 | 落定动作 |
|---|---|---|
| 大数字 | serif 巨号 + 下 hairline + mono 标签 | 里程表滚动 60–90f，末 4f SLAM（scale 1.04→1）+ 朱红 hairline 闪 2f |
| 柱阵 / 折线 | 墨色柱、hairline 轴，峰值柱朱红 | 逐柱 spring 生长（stagger 3–5f），峰值柱最后落、对拍 |
| 热力图 | 365 格（53×7），纸深→amber→vermillion→seal 四级 | 按 seed 随机序点亮，峰值格最后亮并微放大 |
| 榜单 | 横条 + 名次 + 标题 + 阅读数 | 条从 0 生长，名次数字滚动，冠军条朱红 |
| 版式切换 | 卡片/文字块翻转、位移 | 承接上一镜的物体，落到新位置 |
| 时间轴 | 水平 rail + 年份刻度 + 事件点 | rail 从左画出，事件点按时间落下，当前年高亮 |
| 代码 | 白底终端窗 + mono 行 + 行号，关键词用 ink 700、字符串用 vermillion | 逐行打出（3–5f/行），光标闪 |
| 字流 / 标签墙 | 文章标题、标签、版本号排成流动的带 | 无缝横向流动，速度随情绪（−2 至 −8 px/f） |
| 印章 | 朱红方章 + 白文/朱文 + 微压印位移 | 落章 6–8f，纸面轻微凹陷阴影 |

## 6. 内容本体化（本片最重要的一条）

- **全片零网站截图、零书封、零页面快照**。信息一律用「数据件」呈现：标题文本、数字、代码、版本号、日期、地名。
- 每镜至少一个**可读主体**：一个数字、一句标题、一段代码、一个图形——观众暂停能读到东西。
- 网站截图若确需出现（如证据），只允许 ≤1 帧且 ≤1/6 画幅——本片原则上不用。

## 7. 转场

- 默认**硬切**（80%）：切在拍点上，前镜尾帧与后镜首帧同一物体/同一位置承接（交接态）。
- 幕界：**白闪 2–3f 或朱红满屏 3f**（只三幕上线用朱红）；或「横移擦除」1 次（冷开场 → 一幕）。
- 禁止：纸翻、墨洇、飞白、模糊溶解、粒子转场（旧版语汇全部退役）。
- ShotShell 提供统一镜首/镜尾遮罩能力，镜文件零工作；`cut` 为逐像素零 DOM。

## 8. 手作签名点（克制保留）

- 印章 / 手写「wuh.site」：全片 ≤4 处（片名落版、二幕末、六幕人卡、末镜）。
- 墨点：只作「事件点」的视觉母题（时间轴节点、提交点），不作为装饰粒子。
- 家族片头片尾自带签名，正片不再重复。

## 9. 每镜一场戏（四问，缺一问返工）

1. **承接**：首帧态 = 上一镜尾帧交出的东西（物体/位置/数字）。
2. **触发**：本镜主动作是什么、谁执行（数字滚动 / 柱生长 / 印章落下 / 光标点击 / 卡片翻面）。
3. **展开**：内容分层表演，节奏用帧级数组（stagger）；多点落定前疏后密，末点对拍。
4. **交接**：尾帧态交给下一镜，写进分镜「尾帧」列，下一镜从同态起步。

**禁**：整段淡入当主动作；静止超过 12f 无微动；装饰性元素先入场。

## 10. 确定性与时间轴铁律

- 随机只用 `random(seed)`；禁 `Date.now` / `Math.random` / 渲染期网络请求。
- 一镜一文件、局部帧从 0 起、自包含、不透明底、无 `<Audio>`。
- 帧数唯一真源 = `shots-manifest.json`；storyboard 对账表由 `shots.mjs import` 反向核对。

## 11. BGM

- 家族口径：90 BPM 网格（20f/拍），多段交叉淡化对拍；本片气质 = 明亮、电子、有推进感（不是旧版氛围/深空）。
- CC-BY 曲目（incompetech 等），署名清单随片交付；`public/wuh-site-intro-v3/score-bright/`。
- 情绪节点与画面重音对齐：二幕沉默段音乐退到最薄（单一持续音），三幕上线回满，六幕收在单音。

## 12. 禁用清单（违反即返工）

- 整屏近黑底 / 星点粒子场 / 扫描线 / HUD 辉光框（旧科技皮）。
- 网站截图、书封、页面缩略图当画面主体。
- 蓝青紫与彩虹渐变；霓虹描边；玻璃拟态。
- 与数据无关的装饰线框、伪 3D、光晕粒子。
- 底部字幕条（本片字幕 = 画面内动能排版）。
- 空镜停留 >3f（二幕沉默段除外，且必须有反讽数字在场）。
