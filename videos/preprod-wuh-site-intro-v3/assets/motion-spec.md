## 2. 设计基调

### 2.1 一句话

**纸上的编年史，两种材质。** 纸面承载记忆与数据（暖纸、暖黑、朱红钤印，Remotion 重绘）；真实截图是暗色暖棕「屋内之眼」，一律经「窗」入画。镜头不炫技——`locked` 是默认，push-in 全片只给两处重音（镜 17 / 镜 28），环绕 0 次。

### 2.2 四条不可违反的基调

1. **双材质，不混染。** 纸面镜禁科技 UI 语汇；截图镜禁纸纹重染——截图自带采集端统一的暗色暖棕主题，调色层只做 vignette 与 ±5% brightness 微调。
2. **墨点是时间轴的原点。** 2019 落下（镜 2）、2025 停成四点（镜 20/21）、入院铺成 46 枚（镜 30）、2026 重新洇开（镜 25 苔痕 → 镜 55 衍生之树 → 镜 62 落款一滴与开篇同形同位，`seed=s01-ink` 复用，母题闭合）。墨点统一暖黑芯、褐边；**只有印章与品牌朱红元素用朱红**。
3. **全片没有一次急推、没有一次环绕。** push-in 仅镜 17（第一行代码）与镜 28（上线点亮）两处；8-4 知识卡「环绕」是卡片动势（`FN-12`），机位不环。速度曲线只允许缓起缓停，「匀速」用 `CM-15` plateau 档。
4. **全片无 SFX。** 禁 `<Audio>`；所有落定听感由画面动作（纸震、涟漪、钤印、白闪、字落）与音乐承担。

### 3.5 窗语汇令牌（WIN，5 枚 · v3 新增）

> 适用于一切以登记表 S01–S12 与 P 型物证打底的镜（§2.3）。**四条铁律：**
> 1. **素材像素不变形不扭曲**：transform 只允许对窗容器做**等比** scale / translate，scale 上限 **1.06**（`WIN-03`）；禁 rotate3d / skew / 逐像素位移 / 局部拉伸。
> 2. **动效只作用于窗与叠加层**：窗框、亮带、流光、标注、数字、字幕层可动；截图位图本身只作为被揭示对象。
> 3. **禁裸贴全屏**：截图必须经窗语汇入画；全片唯一例外是镜 28 整页点亮（白闪特例，`WIN-05`）。
> 4. **截图镜调色克制**：只允许 vignette（四边 linear-gradient）与 ±5% brightness 微调；重染色禁止（采集端已统一暗色暖棕主题）。

### 7.2 Remotion 可实现约束

- **原语白名单**：`interpolate` + `Easing.*`、`spring()`、`interpolateColors`（仅 `FN-31`）、CSS `opacity` / `transform`（translate/scale/rotate/rotateX/rotateY）/ `filter`（blur/brightness/saturate）/ `clipPath` / `mixBlendMode` / `strokeDasharray/offset`。禁 UE / After Effects 专属概念：景深用多层 blur 等效，bloom 用复制层 blur + screen 等效，升降用 translateY，@view-transition 用 `FN-32` CSS transform 模拟，不调浏览器 API。
- **只动合成友好属性**：禁动画 `width/height/top/left/margin/padding`、`box-shadow`、大图 `background-position`（白光线用 scaleX，白闪用 filter brightness）。
- **确定性随机**：一律 `random(seed)`；禁 `Math.random()` / `Date.now()` / `performance.now()`；同 seed 预览与渲染同结果。
- **禁全屏 radial-gradient**：局部 radial 仅笔尖 28px（`FN-20`）、印章朱晕 ≤240px、墨点核心 10–14px、单颗光尘 2–5px、`GR-03`/`GR-07` 局部窗光；暗角晨光一律四边 linear 或 clipPath。纸纹用预渲染 tile，禁 `feTurbulence`。
- **禁 `<Audio>`**：场景树无音频节点；白闪、钤印、回车、唱针落定的听感由音乐与画面承担。
- **窗语汇纪律进实现**：截图 `<Img>` 只允许被窗容器（等比 transform ≤1.06）与叠加层包裹；任何对 `<Img>` 本身的非等比 transform、filter 重染色、逐像素位移一律违规（`WIN` §3.5 四条铁律）。
- **数据口径写死**：§7.1 `DATA_CONST` 全部数字入常量；版本雨画 118 颗（119 是含 v2.0.0 的 tag 总数）；热力图 365 日格（13,603 是活动合计不是格数）；镜 30 墨点 46 枚（点亮非计数）。
- **线性例外**：仅 `FN-24` 黑胶 5s/圈、`FN-35` 跑马灯两处物理匀速；其余一切运动走 `CV-01–07` 与 `CM-15` 包络。
- **交接态协议**：每镜末帧必须可冻成静帧；下一镜首帧同状态起步（同纸面/同窗口/同 litSet/同墨点相位）；镜 28→29 与镜 46→47 的交接做首尾帧像素对比验收。
