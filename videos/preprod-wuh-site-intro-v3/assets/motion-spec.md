### 0.1 六条动效基调（本规范总纲）

1. **纸面不动底**：纸色只在 `FX-06 PAPER-TONE` 明写处压暗/回暖（s08/s19/s20/s25），其余镜纸底恒定；动的是墨、朱、金与数据件。
2. **一镜一主动作**：每镜恰一个「主落定」并落 20f 拍网；其余元素只做 stagger 支撑，禁同时启动（`ai-director` §7.3 Overlap 错峰 3–6f）。
3. **落定必对拍**：56 镜主落定帧 = 20f 整数倍（§5.1 全列）；落定瞬间完成 SLAM / 印章 / 描边填实，BGM 点在此。
4. **印刷感替代表演欲**：位移 ≤ 24px（页移/卡移除外）、scale ≤ 1.15、过冲 ≤ 6%（`springPop` / `sealStamp` 例外）；全片零环绕、零急推、零抖屏。
5. **数据是主角，装饰不动**：无装饰粒子场、无扫描线、无 HUD 辉光、无伪 3D（`style-anchor` §12）；每镜可读主体 ≥ 画幅 1/3。
6. **切即交接**：镜尾帧 = 下镜首帧同态（同物体 / 同位置 / 同数字 / 同纸色），交接格逐镜写明（§4 末列）。

## 1. 节奏与重音

### 1.1 90 BPM 网格

- 1 拍 = **20f**；半拍 = 10f；16 分格 = 5f；短语 = 4 拍 = 80f。
- **56 个镜 start 全部落在 10f 网格**（storyboard §3 已机器核对），其中 33 镜落在整拍、23 镜落在半拍；镜窗连续无缝。
- **主落定帧全部吸附整拍（20f 整数倍）**——这是本片最硬的一条节奏纪律：任何「数字落定 / 印章落定 / 柱阵收官 / 卡片落位」不得落在半拍或任意帧。
- 幕交界帧：**600 / 1500 / 2400 / 3300 / 4500 / 5200 / 5700**——全部是整拍（30 / 75 / 120 / 165 / 225 / 260 / 285 拍）。

### 6.3 SLAM 落定规则（`NUM-03` 硬口径）

1. **落定位置**：每镜主动作落定帧必须是 20f 整拍（§5.1），不得提前/延后 1 帧。
2. **末 4f 压实**：scale 1.04→1（`cineEaseOut`）+ 纸面整组位移 1px + 朱红 hairline 闪 2f（`INK-03`）。
3. **不 overshoot**：滚动值不得短暂超过真值（`CURVES.numRollOut` 单调递增到 1）；数字落定后 6f 内禁止再变。
4. **同镜单钩**：一镜只允许一次 SLAM（多数量同镜时用 stagger 错峰，末枚才是钩；如 s02 八数、s48 三数错 8f）。
5. **滚动即静止**：数字滚动期间同镜其余元素**全部静止**（`ai-director` §7.3 Staging），防止抢焦点。
6. **格式纪律**：千分位（1,243 / 64,985）、百分比 1 位小数（49.8% / 97.2%）、天数不带单位（156 天由标签承担）；数字一律真数字形（lining figures，`style-anchor` §2）。

### 6.4 唯一例外：s19 的「4」「0」（`NUM-04`，需 Lead 裁定）

- 分镜与 `style-anchor` §3 明写：s19 是全片唯一允许「空 / 暗」的镜，**几乎不动**，只有「4」「0」各一次 6f 呼吸。
- 若按「凡量必滚」把 4 / 0 做成滚动，会给出「有过程、有能量」的错觉，直接破坏沉默段语义；且「0」从任何数滚回 0 都是**伪造过程**。
- 处置：`NUM-04` 浮出 + 呼吸（不滚）。这是全片**唯一**豁免「凡量必滚」的镜，已在此显式登记，制作期不得扩大到其他镜。

### 6.5 其他数据纪律

- **轴先稳、数据后动**：所有图表镜先 `CH-02` / `CH-03` 立轴（s14/s23/s37/s47/s54），再走数据。
- **峰值唯一**：朱红描边只给「最重要的那一个」（s15 的 2024、s23 的 192、s35 冠军、s37 峰值格、s40 周末合并），其余走 `FX-07` 去色。
- **禁静态图表**：即便图表只出现 60f，也必须有生长/点亮过程；禁「先展示最终值再动」。
- **禁重绘**：数据切换用 morph/连续插值（`NUM-05` / `CH-05`），不卸载重建（否则跳帧且缓存失效）。

## 7. 确定性与帧号铁律

1. **随机只用 `random(seed)`**（`remotion` 导出）；**禁 `Math.random()` / `Date.now()` / `new Date()` / 渲染期网络请求 / 渲染期读文件**。同 bundle 同帧同像素是镜级缓存成立的前提（`shot-spec` §3 规则 5）。
2. **seed 命名固定**（见 §7.1），同一 seed 在同一镜内恒定；跨镜不得复用同一 seed 生成不同内容（除显式母题复用，如藏印 seed = 镜号）。
3. **局部帧 0 起**：镜文件不自带 `<Sequence>`，`useCurrentFrame()` 天然从 0 起；**禁 `frame - startFrame` 手算偏移**（`shot-spec` §3 规则 1）。
4. **一镜一文件、自包含、不透明底**：禁 import 其他 `shots/`；import 白名单 = react / remotion / brand 令牌 / 本片 `motion-tokens` / 本片 `components/` / 官方 `@remotion/*`（版本钉死无 `^`）。
5. **禁内联色值 / 字体**：一切颜色走 `FILM_COLORS` / `colors`，字族走 `fontFamilies`；白闪与朱红满屏用**底色切换**而非叠白色大矩形（保证不透明底与镜级缓存像素）。
6. **禁 `<Audio>` / SFX 进镜**：BGM 只在装配层 `SiteFilmAudio.tsx`（`shot-spec` §4）。
7. **禁猜 pathLen**：描画一律 `evolvePath` / `inkDraw`（真长度）；禁用 `strokeDasharray={1600}` 类魔数。
8. **禁 `Math.sin` 有机运动**：颤动/漂移/尘埃一律 `noise2D(seed, x, y)`（**三参**，`remotion-capabilities` §1）。
9. **线性曲线例外（仅 2 处，须注释）**：`GR-06` 无缝带流动、`FX-03` 朱红擦拭——其余任何位移/缩放/入退场禁线性。
10. **静止上限 12f**：任何元素静止不得超 12f（除 s19 长镜、s56 末 20f，且必须保留微呼吸 `FX-08` / `EN-07`）；禁「整段淡入当主动作」（`style-anchor` §9）。
11. **帧数真源**：`shots-manifest.json`；本规范与分镜对账表都由 `shots.mjs` 反向核对，production 改帧只改 manifest。
12. **快段落定距镜尾 ≥ 6f / 呼吸段 ≥ 20f**（§1.1）；落定后余量用于交接态（§4 末列）。

### 10.2 不确定 / 需降级 / 需 Lead 裁定的镜（逐条）

1. **s07「每减 1 对一拍」物理不可行（必降级）**：30 次递减 × 20f/拍 = 600f，但该镜只有 110f。**降级为**：`NUM-02` 连续倒滚 70–80f，个位约 2.3–2.5f/翻、十位 5f 间隔，归零点对拍 800。若坚持「每减 1 对一拍」，需把 s07 延长到 ≥600f 或改成 6 个 5 天分段——两者都会破坏幕窗，**建议按降级执行**。
2. **s33 大数滚动与尾帧冲突（必降级）**：分镜写「滚动 70f 落定、末 4f SLAM」，但该镜 100f 且前 20f 要让标题墙退窄带 → 只剩 76f，SLAM 后仅 6f 余量。**降级为**：退带 20f + 滚 56f + SLAM 4f，落定 3500、余 20f。若保留 70f，落定会压到 3514（非整拍）且没有交接余量。
3. **s37「52 批 × 约 2.5f」超窗（需压缩）**：52×2.5 = 130f > 140f 镜长扣除入场 30f 后只剩 110f。**降级为** 批距 1.65f（后段更密），峰值格 112–120f 放大，落定 3940。
4. **s45 JSON「逐行」口径（需明确）**：JSON 共 50+ 字符，若按 3f/字 ≈ 150f 远超 90f 镜长。**定为行级 8.5f/行（3 行）**，这是 `TX-02` 的 `jsonLine` 档；若评审要求逐字，则本镜需加长或删字段（建议不删：issue/state/labels 是真实结构）。
5. **s19「4」「0」不滚 vs 凡量必滚（需 Lead 裁定）**：见 §6.4。我的判断是保留反衬（不滚），因为长镜沉默段的语义就是「数字不动」；这是全片唯一豁免，若 Lead 要求一视同仁，需改分镜（该镜将失去唯一性）。
6. **s43 一镜双主体（确认降级）**：4 条弹幕 + 标签云同镜，观众只能读到一个主体。**只认标签云为可读主体**，弹幕降为「进入动效」（分镜 §8-10 已这样声明，本规范固化）；弹幕退净帧固定 4470（50f）。
7. **s02「每枚落定纸面位移 1px」（需实测）**：1920×1080 下 1px 位移在编码后可能不可见。**建议**改 1.5–2px 或整组 scale 1.002 的「呼吸式」位移；若坚持 1px，需在首帧渲染后抽帧验收。
8. **s18 七枚 commit hash 可读性（建议降级）**：80f 内 7 个 12px mono hash 同时读不完。**建议**：首末两点常显，中间 5 点 6f 后 opacity 降到 0.4（仍可暂停读到，但不抢「七点弧」主形）。
9. **s41 书脊「19 条描顶」弱可读（已缓解）**：146 条中 19 条描顶在 80f 内难辨识；分镜已有 `BOOKS · 19 FINISHED` 标签兜底，本规范要求 19 条描顶用 `accent` 2px（非 1px）并配 `GR-09` 顶部 8% 提亮。
10. **s46「转绿」措辞与禁绿冲突（已消解）**：分镜列写「自左转绿（墨色 + 朱红勾边，不用绿）」——本规范 `FL-02` 固化**禁 `statusGreen`**，亮起 = 墨块 + 2px 朱红勾边。
11. **s52 余量最小 + 尾 10f（确认快段例外）**：17 字 / 70f（上限 18 字）必须按句长预排；落定 5340 尾 10f，属 §1.1 快段例外，不做延长。
12. **s26 朱红满屏的 BGM 对音（需配乐层确认）**：2790 是半拍（139.5），若 BGM 把「满色 hit」放在 2800 会晚 0.33 拍。**建议**：hit 落 2790–2793 这 3f 内（可自由落点，不是整拍），2800 再落「上线」露出的一记弱音。
13. **s32 文章墙无缝循环（实现风险）**：46 条标题 5 行流动，需内容重复 ≥1.5 屏才能无缝；重复会造出「92 条标题」的观感，**建议**每行独立相位（不同起始 x），避免整墙同步跳回。
14. **s39→s40 点阵收拢几何（已给解释）**：706 天点阵与七柱不是同量纲（706 天 vs 1,243 提交）。`GR-02` 定为「点先按星期几收成 7 堆，柱再从堆高生长」，观众读到的是「把日子归到星期」，不是「706 变 1,243」。
