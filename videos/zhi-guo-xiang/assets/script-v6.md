# 《风陵 · 致郭襄》剧本 v6（海边倒叙 · 节奏稳定 · 不设时长）

> 2026-11-01 · 取代 v5。诗六行逐字不改。
> v6 只做一件事：把 v5 里**逻辑没站稳**的地方补上——让「一见」成立、让「误读」具体、让「翻纸背」可信。

## 一句话

一个男人在海边看晚霞时，读到一张旧纸；纸上是另一个女人的一生——她为一束只亮过一夜的光，找了二十四年。

## 节奏原则

1. **一段一个呼吸**：每段按自己需要的长度走，不为凑时长砍呼吸。
2. **转场只有一种**：云。
3. **字幕不赶**：一行字落定，画面至少留两拍。
4. **越往回越慢（镜头长度的梯度）**：
   - 现在线 2–4 秒／镜
   - 晚年 5–6 秒／镜
   - 出家 6–8 秒／镜
   - 寻人 8–10 秒／镜
   - **十六岁 10–15 秒／镜**（全片最慢）
5. **总时长不预设**，以每段站得住为准（预计 5–7 分钟）。

## 现在线（他）

海边礁石，黄昏。他坐着，膝上压一张旧纸。
浅色短袖衬衫、深色长裤、白鞋、眼镜、斜挎一只蓝包。
只见背影与侧后：眼镜腿、衬衫领、坐姿。

**他必须在场**：倒叙三次回到他（每次 2–4 秒，只给手、海浪、云的微变化）。
- 她搁笔之后：他抬头，海面亮了一线。
- 判词说完之后：他的手指在纸边停住。
- 华山之后：他闭了一下眼睛，海风把纸角掀起。

## 结构

### 一、现在 · 海与云

海浪、礁石、远天云霞翻涌，远山起雾。
他坐下，把一张旧纸摊在膝上。
纸上是六行诗：前四行墨色已旧；第五行只有一个「其」字，旁边洇着一团墨。
他抬头看云。镜头穿过云——

**诗第 1、2 行**：我走过山时，山不说话／我路过海时，海不说话。

### 二、晚年 · 灯（倒叙第一站）

道姑在灯下写诗。纸上已有四行。
她写第五行「其实我只是爱上了峨眉山上的云和霞」，停在「霞」之前。
笔悬着。一滴墨落下，洇开——就是海边那张纸上的一团墨。
她搁笔，看向窗外。窗外也是云霞。

→ **回到他**：海面亮了一线。

### 三、出家 · 剑（第二站）

晨课，她教弟子，说话不出声。
剑挂上墙，再没取下来。
两枚金针放进经卷夹层——没有许愿。
雪夜断墙，剑插在雪里，鞘上三道火燎痕：**父母在城破前铸的，不是他留的信物。**

### 四、寻 · 判词（第三站）

一个渡口接一个渡口，每个都像风陵渡。驴、剑、行囊。
茶楼说书人（画外，真诚、克制，讲到动情处停一停）：
> 「那郭襄女侠，三枚金针，三个愿望——她一个也没舍得用。」

**而画面里，她刚在渡口用掉了一枚，救一个落水的人。**
世人连这个都记错了。她听见了，没有回头。

街边孩子唱童谣，天真，不知道自己在唱一个女人的一生。
传抄的纸页越摞越高。
她在茶棚想开口，锣声响起，没人听。她低头喝完那碗茶。
救人之后，她看着掌心剩下两枚，很久。

> **语气铁律**：没有人恶意。全世界都在温柔地替她解释，而她无法反驳。

→ **回到他**：手指在纸边停住。

### 五、十六岁 · 烟花（终点，全片最亮）

**风陵渡夜 · 客栈**：火塘边一圈剪影，她坐最外圈只听。第一次听见「神雕侠」。
**风陵渡夜 · 出手**：她走出客栈，被两个醉汉拉扯斗篷。一个独臂人影从火光里过来，没说话，一抬手，两人退了。
　　　　她抬头——只看见一个背影、一只空袖，和天上一只大雕的影子掠过。
　　　　他走了。她怔在原地。
　　　　（她此刻还不知道这是谁；回到客栈才听人说「神雕侠」。**她先看见的是背影，后知道的是名字。**）
**金针**：她的掌心摊开，三枚金针。赠予者不入画。
**生日夜**：满城烟花炸开，火金铺满夜空。她仰头，眼睛被照亮，烟灰落在肩上。
　　　　远处高处，一个深墨长袍、右袖空垂的背影，正看着这座城——**烟花是他为她放的**。
　　　　她不知道。观众知道。
　　　　字幕后落：**满城烟火，本是军情。**
**华山**：云海之上，他转身走进雾里，没有回头。她站着，没有追。

→ **回到他**：他闭了一下眼睛，海风把纸角掀起。

### 六、现在 · 霞（结尾）

回到海边礁石。云霞与十六岁那夜的烟花叠在同一帧上。
他低头，把纸翻过来——**背面有字，墨色如新**：第五行、第六行，写得完整。
（不是墨迹自己变完整；是他一直只看了正面。）

最后一行：**像极了十六岁那年的烟花。**

他合上纸。海风把纸角掀起一下。天还没黑。

## v6 改了什么（六处）

| # | 改动 | 解决什么 |
|---|---|---|
| 1 | 加「出手」：独臂人解围 | 让她**先看见背影、后知道名字**，「一见」才成立 |
| 2 | 只给背影、空袖、大雕影子 | 不露脸也能认出是神雕侠，且不破坏「无正脸」 |
| 3 | 说书人说「一个也没舍得用」，画面里她刚用掉一枚 | 误读变得具体、可感——**世人连这个都记错了** |
| 4 | 烟灰落在她肩上 | 让她记住的是「灰」，不是「光」——更接近诗 |
| 5 | 纸背「墨色如新」而非「新墨」 | 去掉魔术感，保住物理可信 |
| 6 | 镜头长度梯度写进节奏原则 | 「节奏稳定」变成可执行的数字 |

## 贯穿线索

| 线索 | 走法 |
|---|---|
| **墨团** | 开场纸上一团墨 → 晚年那滴墨形成它 → 出家小一圈 → 寻人更小 → 十六岁化作烟花里的一粒火星 → 结尾翻到纸背，墨色如新 |
| **云** | 现在线的云 ↔ 她窗外的云 ↔ 峨眉云海 |
| **光** | 灯 → 雪 → 烟花 → 晚霞；越往回越亮 |
| **纸** | 正面写坏，背面写完 |

## 人物

**郭襄 16 岁（武侠写实）**：鹅蛋脸，眉锋略挑、眼尾微上挑，唇薄，眼里有光、有点倔；垂鬟双鬟系青绦；窄袖交领襦 + 半臂 + 百迭裙及踝 + 绑腿布靴 + 斗篷；雪青为唯一衣色。
**约 20 岁**：单髻裹青布巾，褪色雪青短褐，袖口布带束腕，绑腿，背行囊，脸上有风尘。
**40 岁（道姑）**：道髻 + 木簪，深墨道袍，领口一线雪青；不剃度、无戒疤。
**杨过**：深墨长袍，右袖空垂，长发半束；面具；身边一只大雕的影子；全片无正脸。
**他（现在线）**：见 §现在线。
