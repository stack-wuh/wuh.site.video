# 录音稿 v1（开头 / 结尾）

> 2026-11-07 · 给念念的片子，用你自己的声音。
> 你只录两段：**开头**（海边）和**结尾**（照片背面）。中间的故事旁白仍用 TTS，等这两段回来再定。
> 不用一次录好，每句可以录两三遍，我挑。

---

## 一、怎么录

| 项 | 做法 |
|---|---|
| 设备 | 手机自带「语音备忘录」就行，不用外接麦 |
| 环境 | 关窗、关空调/风扇、关电脑风扇声；被子/衣柜前录更干净 |
| 距离 | 离嘴 15–20cm，稍微偏一点（别正对），防喷麦 |
| 姿势 | 坐着，别躺着（躺着气短） |
| 语速 | 比平时慢一点，像晚上跟人说话；**不要朗读腔** |
| 停顿 | 每句之间停 1.5–2 秒（我后期切，宁可多停） |
| 重录 | 每句录 2 遍，第二遍换个语气；我挑 |
| 不要 | 不要加背景音乐、不要加任何效果、不要压限 |
| 文件 | `voice-kaichang.m4a`、`voice-jiewei.m4a`，直接发我 |

**情绪**：开头不是「播音」，是「跟她说一件只有你记得的事」；结尾不是「总结」，是「说完了，看着她」。

时长不用管——**画面会照你的语速重排**，不要为了赶时间念快。

---

## 二、开头（目标 20–24 秒）

> 念念。（停）
>
> 那天我们在海边看落日，我就想把这个故事做给你。（停）
>
> 后来我真的开始做了。（停）
>
> 做到一半，你发我一张落日，说是你拍的。（停）
>
> 我盯着看了很久，半天没回你。（停）
>
> 太巧了。（停长一点）
>
> 巧得我差点以为，你知道了。

**导演提示**
- 「念念」两个字轻一点，像她已经坐在旁边。
- 「太巧了」是全段的转折，不要用力，越轻越真。
- 最后一句带一点笑，不是问句，不要上扬。

---

## 三、结尾（目标 26–30 秒）

> 念念。（停）
>
> 郭襄的三枚金针，都用完了。（停）
>
> 第一枚，她看了他的脸。（停）
>
> 第二枚，她看了一夜烟花。（停）
>
> 第三枚，她让他活了下来。（停）
>
> 我没有金针。（停）
>
> 我只有以后的每一个落日。（停）
>
> 你回头，我就在。（停长一点）
>
> 现在，你知道了。

**导演提示**
- 「第一枚 / 第二枚 / 第三枚」三句节奏要一样，像数三样东西。
- 「我没有金针」放轻，别自嘲，是认真说的。
- 「现在，你知道了」几乎是气声，说完就停，别再补话。

---

## 四、手写那行字（可选，但很值）

结尾有一个镜头：照片翻过来，背面是你写的字。

- 用黑笔或钢笔，在白纸或照片背面写一行：**下次一起看。**
- 自然手写，不要刻意写好看。
- 白天窗边拍，正对、不反光、拍清楚；多写两三张我挑。
- 文件：`handwriting-1.jpg`。

---

## 五、可选：全片旁白也你录

中间的故事旁白有 50 来句（约 3 分钟）。如果你愿意全录，整部片子就变成**你从头到尾在给她讲这个故事**——比 TTS 强得多。

- 愿意的话我另给一份全片录音稿（分幕、带停顿）。
- 工作量：安静环境下 20–30 分钟能录完，可以分几次。
- 先不急，等你这两段录完，听听效果再定。

## 七、如果走「声音复刻」（AI 用你的音色念旁白）

### 7.1 这不是训练，是「复刻」

百炼的 CosyVoice / Qwen-Audio-TTS 支持**零样本声音复刻**：给 10–20 秒干净的人声，建一个音色 ID，之后用它合成任意台词。不用训练几小时，几分钟就能出试听。

- 优点：你只录 20 秒，不用录 50 句。
- 缺点：它学的是**音色和说话方式**，学不到你即兴的语气；念长句可能偏平。所以要先用三句试听，像不像、顺不顺，再决定用不用。

### 7.2 采样文案（约 22 秒，一口气念完）

> 念念，那天我们在海边看落日。天是金的，海也是金的。我想起一个很远的故事，想讲给你听。故事里的人叫郭襄，她在风陵渡，遇见了一个人。她等了他很久，等到天都黑了。

**要求**
- 一口气念完，句子之间正常换气，**不要停超过 2 秒**。
- 用**讲故事的語氣**，轻、慢、往下沉；不要播音腔、不要朗读腔。
- 安静环境、离嘴 15–20cm、不要喷麦、不要背景音。
- 手机录音即可（m4a / mp3 / wav 都行，采样率 ≥16kHz）。
- 文件：`voice-sample.m4a`。

**为什么采样要用讲故事的語氣**：复刻学的是「你怎么说」，不是「你声音长什么样」。用新闻腔采样，念旁白就是新闻腔。

### 7.3 现在的卡点

我试了当前的百炼配置：

- `token-plan` 的 key 只能走 token-plan 网关，那里**没有声音复刻接口**；
- 工作空间的 key 返回 401（失效）。

所以云端复刻现在**差一把标准 API Key**：百炼控制台 → 右上角「API-KEY」→ 创建。你把它给我（只存在本机 `~/.bailian/config.json`），我就能建音色、先用三句试听。

不想给 key 的话，还有两条路：

| 路 | 做法 | 代价 |
|---|---|---|
| 全真人 | 50 多句都你录 | 20–30 分钟，质量最好 |
| 本地音色转换 | 装 OpenVoice / GPT-SoVITS，用 TTS 的节奏换你的音色 | 要下 1–2GB 模型，CPU 跑得慢，质量不如云端 |

### 7.4 我的建议：混合

- **开头、结尾：你的真声**（已经说好）。这两段是全片最私人的部分，必须是真人。
- **中间 50 句：克隆声**。如果试听像你、不僵，就用它；如果僵，再退回「全真人」或「TTS 占位」。

这样最动人的两段是真的，50 句的活交给 AI。
