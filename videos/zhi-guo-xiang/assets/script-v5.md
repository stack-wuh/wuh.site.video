# 《风陵 · 致郭襄》剧本 v5（海边倒叙 · 不设时长上限）

> 2026-11-01 · 取代 v4。诗六行逐字不改。
> v5 的三条总纲：
> **① 节奏稳定优先于时长**——不压 4 分钟，每段按它自己需要的呼吸走。
> **② 他必须在场**——倒叙途中三次回到海边，读的人不能消失。
> **③ 结尾不变魔术**——墨迹不会自己变完整；是他翻到纸背，看见了新写的字。

## 一句话

一个男人在海边看晚霞时，读到一张旧纸；纸上是另一个女人的一生——她为一束只亮过一夜的光，找了二十四年。

## 节奏原则（先定，再写镜头）

1. **一段一个呼吸**：每段有自己的长度，不为凑总时长砍呼吸。
2. **转场只有一种**：云。进云、出云，不玩花活。
3. **字幕不赶**：一行字落定，画面至少留两拍再走。
4. **越往回越慢**：倒叙是往回走，越靠近十六岁，镜头越长、越舍不得剪。
5. **总时长**：按内容需要，不预设上限（预计 5–7 分钟，最终以节奏为准）。

## 现在线（他）

海边礁石，黄昏。他坐着，膝上压一张旧纸。
浅色短袖衬衫、深色长裤、白鞋、眼镜、斜挎一只蓝包。
**只见背影与侧后**：眼镜腿、衬衫领、坐姿——认得出来是他，但看不清脸。

**他必须在场**：倒叙三次回到他，每次 2–4 秒，只给手、海浪、云的微变化：
- 第一次（她写完第五行、搁笔之后）：他抬头，海面亮了一线。
- 第二次（判词说完、她喝完那碗茶之后）：他的手指在纸边停住。
- 第三次（华山他走进雾里之后）：他闭了一下眼睛，海风把纸角掀起。

## 结构

### 一、现在 · 海与云

海浪、礁石、远天云霞翻涌，远山起雾。
他坐下，把一张旧纸摊在膝上。
纸上是六行诗：前四行墨色已旧；第五行只有一个「其」字，旁边洇着一团墨。
他抬头看云。镜头穿过云——

**诗第 1、2 行**：我走过山时，山不说话／我路过海时，海不说话。

### 二、晚年 · 灯（倒叙第一站）

道姑在灯下写诗。纸上已有四行。
她写第五行「其实我只是爱上了峨眉山上的云和霞」，停在「霞」之前。
笔悬着。一滴墨落下，洇开——**就是海边那张纸上的一团墨**。
她搁笔，看向窗外。窗外也是云霞。

→ **回到他（2–4 秒）**：海面亮了一线。

### 三、出家 · 剑（第二站）

晨课，她教弟子，说话不出声。
剑挂上墙，再没取下来。
两枚金针放进经卷夹层——始终没有许愿。
雪夜断墙，剑插在雪里，鞘上三道火燎痕：**父母在城破前铸的，不是他留的信物。**

### 四、寻 · 判词（第三站）

一个渡口接一个渡口，每个都像风陵渡。驴、剑、行囊。
茶楼说书人（画外，真诚、克制，讲到动情处停一停）：
「那郭襄女侠，三枚金针，三个愿望，她一个也没舍得用……后来在峨眉出了家。」
街边孩子唱童谣，天真，不知道自己在唱一个女人的一生。
传抄的纸页越摞越高。
她在茶棚想开口，锣声响起，没人听。她低头喝完那碗茶。
渡口有人落水，她把第一枚金针拍进那人胸口。救人之后，看着掌心剩下两枚，很久。

> **语气铁律**：没有人恶意。全世界都在温柔地替她解释，而她无法反驳。

→ **回到他**：手指在纸边停住。

### 五、十六岁 · 烟花（终点，全片最亮）

**风陵渡夜**：客栈火塘边一圈剪影，她坐最外圈只听。第一次听见「神雕侠」。
**一见**：她走出客栈，夜色里，一个戴面具的独臂人影从火光中走过。她怔住。他不看她，走过去了。
**金针**：她的掌心摊开，三枚金针。赠予者不入画。
**生日夜**：满城烟花炸开，火金铺满夜空。她仰头，眼睛被照亮。
　　　　远处高处，一个深墨长袍、右袖空垂的背影，正看着这座城——**烟花是他为她放的**。
　　　　她不知道。观众知道。
　　　　字幕后落：**满城烟火，本是军情。**
**华山**：云海之上，他转身走进雾里，没有回头。她站着，没有追。

→ **回到他**：他闭了一下眼睛，海风把纸角掀起。

### 六、现在 · 霞（结尾）

回到海边礁石。云霞与十六岁那夜的烟花叠在同一帧上。
他低头，把纸翻过来——**纸背上有字，是新墨**：第五行、第六行，写得完整。
（不是墨迹自己变完整；是他一直只看了正面，背面她早就写完了。）

最后一行：**像极了十六岁那年的烟花。**

他合上纸。海风把纸角掀起一下。天还没黑。

## 贯穿线索

| 线索 | 走法 |
|---|---|
| **墨团** | 开场纸上一团墨 → 晚年那滴墨形成它 → 出家段小一圈 → 寻人段更小 → 十六岁化作烟花里的一粒火星 → 结尾翻到纸背，墨是新的 |
| **云** | 现在线的云 ↔ 她窗外的云 ↔ 峨眉云海；两线只靠云连通 |
| **光** | 灯 → 雪 → 烟花 → 晚霞，越往回越亮；晚霞与烟花同色 |
| **纸** | 正面是写坏的六行；背面是她写完的六行 |

## 人物

**郭襄 16 岁（武侠写实）**：鹅蛋脸，眉锋略挑、眼尾微上挑，唇薄，眼里有光、有点倔；垂鬟双鬟系青绦；窄袖交领襦 + 半臂 + 百迭裙及踝 + 绑腿布靴 + 斗篷；雪青为唯一衣色。
**约 20 岁**：单髻裹青布巾，褪色雪青短褐，袖口布带束腕，绑腿，背行囊，脸上有风尘。
**40 岁（道姑）**：道髻 + 木簪，深墨道袍，领口一线雪青；不剃度、无戒疤。
**杨过**：深墨长袍，右袖空垂，长发半束；面具（风陵渡夜）；全片无正脸。
**他（现在线）**：见 §现在线。
