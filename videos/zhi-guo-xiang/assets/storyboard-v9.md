# 《风陵 · 致郭襄》分镜 v9（38 镜 · 七幕 · 一镜一事件）

> 2026-11-02 · 依据 `script-v9.md`。诗六行逐字不改。
> 机器真源：`videos/preprod-zhi-guo-xiang/assets/storyboard.md`（`shots.mjs import` 解析）；本文件是设计说明与逐镜表。
> v9 的三条硬规矩：
> 1. **一镜一事件**：每镜回答「这一镜里，什么变了」。
> 2. **字幕只给事实**：情感交给画面和音乐；每条字幕删掉会少知道一件事，才留。
> 3. **剑不离背，杨过不出脸**：寻人全幕剑背在背上；杨过永远是背影——郭襄自己就没看见。郭襄只给三次脸：S05 听见名字、S13 仰头看烟花、S26 拈针，只在她不设防的时候。

## 三、全片的动作：舍不得

五次「舍不得」，一次写下来。

| 镜 | 舍不得什么 | 怎么演 |
|---|---|---|
| S19 | 舍不得承认他三天前就走过了 | 雪在盖脚印，她不走 |
| S22 | 舍不得解释 | 听见了，不回头 |
| S24 | 舍不得把那句话说出口 | 张了一下口，锣响，把茶喝完 |
| S26 | 舍不得用掉那枚针 | 举到眼前，放下手 |
| S34 | 舍不得写完那句诗 | 停在「霞」前，让墨吃掉 |

第五次在 S37：她把纸翻过来，写在背面——**前四次都有别人在，第五次只有她自己。**

所以 S34 的墨不是暴力，是时间：她让墨落下去，替她把最后那个字吃掉，这样她就可以再坐一会儿。

## 四、镜头语法

v8 的问题之一是二十多个镜头都用同一个「缓慢推近」。v9 按幕配语法：

| 幕 | 语法 | 目的 |
|---|---|---|
| 序 | 大远固定 → 微距极缓推 | 天地 → 一张纸，落差 |
| 风陵渡 | 静 → 静 → 近 → 静 → 晃 → 定 → 仰 → 俯 | 从远到近，从静到晃 |
| 烟花 | 大远固定 → 大远固定 → 长焦上摇 → 特写固定 → 横移 | 唯一一次让大场面完全不动 |
| 寻 | 俯 → 横移跟拍 → 侧后跟拍 → **大全固定** → 中近固定 → 推 → 固定 → 手持晃 → **绝对静止** → 俯 → **微距固定** | 动静交替，茶棚处归零 |
| 出家 | 全固定 → 中缓推 → 微距俯 → 特侧影 | 一镜比一镜近 |
| 写诗 | 中 → 特 → **微距长固定** → 微距 → 中 | 停在笔尖上最久 |
| 尾 | 空镜 → 微距 → 空镜 | 两个极端景别夹一张纸 |

**两处刻意不动**：S12 满城烟花（最响的画面不运镜）、S33 笔悬（最静的画面不动）。一动一静，是同一套逻辑的两端。

## 五、动效清单（代码动画，按优先级）

### P0 · 压在音乐重音上的三处

1. **S28 剑入匣**（170–177s，曲子第一次大高潮）
   剑从背上滑下 → 横置于匣中 → 匣盖合上。三段位移，不用新图，用 `Sword` 分层 + transform。
2. **S33/S34 笔悬与墨滴**（201–214s，曲子第二次最高潮）
   S33 只有一滴墨将落未落；S34 落下、洇开、吃掉那个字。已有 `blot`，补笔尖悬停的微颤。
3. **S19 差一点**（113–120s，曲子第二次高潮的衰减）
   雪粒横飘；脚印逐个被雪盖住；一片黑羽旋转落下。这是新镜，全部代码画。

### P1 · 母题回环

**火**是全片唯一的彩：火塘（S04）→ 烟花（S11–S14）→ 灯焰（S30/S31）→ 窗外云霞（S35）。
同一个粒子系统，三次出现，尺度递进：一炉 → 满城 → 一盏。观众不会注意，但会觉得「这是同一部片子」。

**金**同理：金针（S10/S25/S26）→ 烟花火金（S12）→ 瞳仁的光（S05）。

### P2 · 跨镜连续性

- **S13 → S14**：同一层烟灰粒子跨镜延续，把「她仰头」和「灰落肩」连成一个动作，而不是两个镜头。
- **S17 → S18**：剑穗摆动的相位接上，观众感到「还在走」。

### P3 · 幕间转场

七幕之间用「墨滴洇开」转场，12–16 帧，落点：
序→风陵渡（S02 末）、风陵渡→烟花（S10 末）、烟花→寻（S15 末）、寻→出家（S26 末）、出家→写诗（S30 末）、写诗→尾（S35 末）。

比黑场高级，也比硬切更像「一页翻过去」。
