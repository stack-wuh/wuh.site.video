## 5 · 如果明飞的 API 能声音复刻：采样文案（约 22 秒）

> 念念，那天我们在海边看落日。天是金的，海也是金的。我想起一个很远的故事，想讲给你听。故事里的人叫郭襄，她在风陵渡，遇见了一个人。她等了他很久，等到天都黑了。

要求：一口气念完，句间正常换气、**停顿不超过 2 秒**；讲故事的语气（轻、慢、往下沉），**不要播音腔**；安静房间、离嘴 15–20cm；手机录音即可，采样率 ≥16kHz。
**为什么不能用播音腔采样**：复刻学的是「你怎么说话」，不是「你声音长什么样」。用新闻腔采样，念出来就是新闻腔。

## 6 · 参数与风格

| 项 | 建议 |
|---|---|
| 基调 | 低声、克制、像讲别人的往事。不要激昂，不要朗诵腔 |
| 语速 | 0.9–0.95（正常人的「讲故事」速度） |
| 男声音色 | 30 岁上下，中低音，偏哑一点，不要播音员 |
| 女声 16 岁 | 清亮、偏轻、带点倔；不是甜 |
| 女声 40 岁 | 同一音色 + 语速 0.85 + 更多气声 |
| 输出 | 24kHz 单声道，mp3 或 wav 都行 |
| 后期处理 | **不要**加混响、不要加 BGM、不要做美化；降噪可以有，但别削掉气声 |
| 句尾 | 保留自然收气，不要硬切；前后留 100–200ms 静音，我这边会重新铺 |
| 一致性 | 同一音色、同一参数、同一 seed（若 API 支持），避免每句音色抖动 |
