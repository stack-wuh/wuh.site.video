# 《风陵 · 致郭襄》旁白重设计 v7

> 2026-11-07 · 回应两条意见：① 旁白没把故事交代清楚，要深入前因后果、断句与节奏像真人；② 旁白 / BGM / 男声 / 女声要能切换，长段无旁白时 BGM 必须顶上来。
> 本文件是**设计稿，不是执行版**。确认口径后再改 `scripts/voice/lines.json` → 重配 `voice-track-v7.wav` → 重混 `mix-v7.wav`。
> 成片不变：7350f / 245.0s；诗六行（灵心）逐字不改、落点不动。

---

## 零 · 一句话

**v5 的旁白是「情绪碎片」，v7 改成「一个人把故事讲给另一个人听」**：男声负责把前因后果讲明白（谁、为什么、后来怎样），女声只在她自己开口的时刻出现（四句引语），BGM 在三个高潮段完整接管（烟花 24s / 寻找 12s / 墨滴 13s），并且在任何 ≥3s 的无旁白窗口自动抬高 6dB 从「托底」变「主角」。

## 一 · 这个故事的前因后果（旁白必须让观众知道的 12 件事）

按时间排序，标 ★ 的是 v5 完全没交代或交代错的：

| # | 事实 | v5 有没有 |
|---|---|---|
| 1 | 郭襄是郭靖、黄蓉的女儿，生在襄阳 | ✗ ★ |
| 2 | 十六岁那年她一个人从襄阳跑出来，家里人当她娇养，没人信她能走远 | 半（只说了「没人信」） |
| 3 | 她本要去别处，只是路过黄河边的风陵渡 | 半（「本来是要路过的」被删了） |
| 4 | 在渡口客栈听人讲「神雕侠」：独臂、大雕、来去无踪 | 半（只有「他叫杨过」字幕） |
| 5 | 夜里醉汉扯她斗篷，独臂人出手，一句话没说就走了 | ✗ ★ |
| 6 | 她追出去，只看见背影、空袖、天上一只雕的影子——**她没看见他的脸** | 半（画面演了，旁白没锚定） |
| 7 | **金针的准确含义**：见此针如见他面；托人持针传命，他必办到——是**三次差他办事的机会**，不是「三个愿望」 | ✗ ★（v5 说成「三次见他的机会」，字幕说「许三个愿望」，两处都错） |
| 8 | 十六岁生日那夜，满城烟花是他为她放的；他在城头看了她一整夜；**她不知道** | 半（画面+字幕，旁白只在最高潮上压了一句） |
| 9 | 就为了再见他一面，她背着剑一个渡口一个渡口地找，找了**二十四年** | 半（女声独白说了「很多年」，没说「为什么」） |
| 10 | 她每次都晚三天；赶到时雪已盖住脚印 | ✓（b05/b06，写得好，保留改写） |
| 11 | 她终于赶上一次，用掉**唯一一枚**金针，只求他摘下面具让她看一眼；剩下两枚，此后再没动过 | 半（b08，但「三次见他的机会」错了） |
| 12 | 四十岁在峨眉出家；剑收进木匣再没取出；两枚金针夹进经书没烧掉；她留下一首诗，写十六岁那年的烟花，最后一句舍不得写完，写在纸背 | 半（缺「为什么出家」与「诗是判词的回答」） |

**金针的因果链是整部片子的发动机**：他给她三枚针（三次托他办事的机会）→ 她只用一枚换「看一眼脸」→ 剩下两枚舍不得用 → 舍不得用 = 舍不得把「还能再见他」这件事用掉 → 于是找了二十四年。这条链不交代，S25「剩两枚」、S26「拈针又放下」、S34「墨滴」全都失去重量。

## 二 · v5 旁白为什么「交代不好」（诊断，带数据）

| # | 病 | 证据 / 后果 |
|---|---|---|
| 1 | **只讲「心」，不讲「事」** | 22 段里 12 段是女声情绪独白；郭襄是谁、金针是什么、为什么找 24 年、为什么出家，四条主因全部缺席。观众看到的是碎片，不是故事 |
| 2 | **金针口径错** | v5 b08「三枚金针，三次见他的机会」；字幕 S10「可以许三个愿望」；原著与 design-v10 §零 都是「差他办事」。三处互相打架，且与 S25「剩两枚舍不得用」的正确读法不咬合 |
| 3 | **人称跳** | 男声 a12「往后的二十四年，让她自己讲」后，女声立刻进入 94–133 近 24 秒连续独白；「我」是谁、为什么突然换人，靠观众猜 |

| 5 | **句子等长、逐句合成** | 10–27 字、全是完整主谓句；合成按条切，句首句尾各带 0.2–0.4s 静默，拼起来一顿一顿（v5 已承认，但没解决「段落」层面的呼吸） |

## 三 · v7 叙述架构：三个声音 + 五种 BGM 状态

### 3.1 三个声音各干什么

| 声部 | 谁 | 只负责 | 不负责 |
|---|---|---|---|
| **男声 · 讲述者**（云健） | 海边读纸的人，讲给念念 | 全部叙事因果：身份、时间、地点、为什么、后来怎样 | 抒情、替她表白 |
| **女声 · 郭襄**（晓晓） | 四十岁的她在回忆 | **只在她自己开口的四个时刻**：找、错过、用针、拈针/火光 | 讲剧情、讲别人 |
| **诗六行**（灵心，不动） | 她写下的字 | 诗本身 | 任何解释 |

**女声从 55s 长独白压到 4 句引语（约 30s）**，这不是削弱她，是把她从「第二个旁白」还原成「一个不解释的人」——这正是 v9 §4.1 立的规矩：她的沉默就是回答。

### 3.2 男/女交接点（全片唯一一次换声，必须干净）

- 男声 **[106.6–111.2]**：「就为了再见他一面，她找了二十四年。」
- 停 0.4s → 女声 **[111.6–115.0]**：「一个渡口，又一个渡口。我在找他。」

此前全是男声第三人称；此后「我」只出现在她自己的句子里。观众不需要猜。

### 3.3 BGM 的五种状态（这是本次混音最大的改动）

| 状态 | 触发 | BGM 电平（相对床） | 用在哪 |
|---|---|---|---|
| **静** | 片头 0–4、茶棚设计静默 | 无 | 0–4；143.5–146（见 §3.4） |
| **托底** | 有人声 | −11 dB 基准 + 逐段 ducking | 全部有旁白段 |
| **让位** | 人声只有 1–2 短句、BGM 正在高潮 | −11 dB + 深 duck（沿用 v6 实测表） | S21、S28、诗 L3 |
| **站出** | **≥3s 无旁白** | **−5 dB（比床高 6dB），0.6–1.0s ramp** | 34.5–44.5、64–88.4、94–106.4、120.2–126.3、133.1–138.5、148.2–151.5、161.4–163.5、189–220（诗与墨滴）、224–239 |
| **收** | 段落结束/出片 | 2–6s 自然衰减 | 片尾 239–245（曲已自然静默，无需处理） |

**「站出」窗口就是观众记住音乐的段落**：烟花 24s（64–88）、寻找 12s（94–106）、墨滴 13s（201–214）。这三段全程零旁白，只靠 BGM + 画面 + 两三条字幕，把「让画面冷下来」这件事从根上解掉。

### 3.4 冷区 133.5–151（17.5s 无有效音乐）怎么处理

现状：第一遍曲到 133.5s 已基本无声（尾奏撤完）；第二遍 151.0 才进来。这 17.5s 里只有童谣字幕、茶棚、一句「我听见了」（v5），是全片最容易「冷」的地方。

三个方案（选一个）：

| 方案 | 做法 | 代价 |
|---|---|---|
| **A 保留设计静默** | 只把「我听见了」换成「我张了张嘴，没说出来」（F，145.0–148.2），另在 133.5–151 垫一层 **−38dB 的极低房间底噪/海风**（不是音效，是「空间还在」） | 茶棚 7.5s 的「空」保留；观众听到的是「静」，不是「断」 |
| **B 第二遍提前** | 第二遍从 **146.5s** 起（曲 41.04），真空缩到 3.0s；后面所有第二遍落点整体前移 4.5s（剑入匣 170–177 仍落在曲 68.5–75.5 高潮内，诗 L3 落在曲 94.5，仍成立） | 改写了「音乐自己走到无声」的设计；与「同一乐句给两次选择」的对位从 4.5s 偏到 0s（其实更准） |
| **C 加一句旁白** | F 143.6–146.6：「我把那碗茶喝完了。」，让静默从 7.5s 缩到 4.5s | 用台词填静，最省事，但 v9 §3.2 明确这场戏「不要字」 |

**我推荐 A**：静默是设计，冷是「没有空间感」，垫一层 −38dB 的底就能解决，不动对位。

## 四 · 断句与节奏：像真人的六条硬规则

1. **一条 = 一个呼吸段**：每条 1–3 句、12–30 字；段内用逗号/破折号造小停顿，段间靠 `lines.json` 的起秒留 0.4–1.2s。禁止把 4 个短句各切成一条（v5 的「一顿一顿」就是这么来的）。
2. **起止落在镜头内**：每条台词的第一个字在镜头切点后 ≥0.3s，最后一个字在下一个切点前 ≥0.3s；不要在硬切/转场遮罩中间起句。
3. **句长错落**：一段里至少有一个 ≤8 字的短句和一个 ≥18 字的长句（例：「醉汉扯她的斗篷。一个独臂的人一抬手，他们就退了。」）——真人说话不会句句等长。
4. **口语连接词**：因为 / 所以 / 后来 / 可是 / 直到 / 那年 / 那天 / 没人信 / 才知道。少用书面语（「自此」「遂」「其」）。
5. **陈述句不许上扬**：语速男 −26%、女 −28%；女声 16 岁的两句（找、用针）用 −18%，40 岁的两句（喝茶、火光）用 −30%，同一把嗓子两个年龄，不换音色。
6. **一条 TTS 内部不换气的地方用逗号**，需要真停顿（>0.6s）就拆条；需要强调的地方用破折号或「——」引出一拍。
