# 《风陵 · 致郭襄》剧本 v3（倒叙 · 云霞为门 · 约 4 分钟）

> 2026-11-01 · 取代 v2 的线性结构。诗六行逐字不改。
> 三条裁决：**主题是「一见杨过误终生」的遗憾**；**出家是道姑，不剃度**；**现在线只见手与窗，片尾不加献词**。
> 缘起：这是作者在看到晚霞与云雾时想起的故事——「云和霞」因此成为全片的门与抓手。

## 一句话

一个人在看晚霞时读到一张旧纸，纸上是另一个女人的一生——她为一个人误了一生，却告诉自己，她爱的是云。

## 结构：倒叙五段

亮度曲线一路递增：**灯 → 雪 → 火 → 烟花 → 晚霞**。越往回走越亮，最后晚霞与十六岁的火光同色。

### 0:00–0:30 现在 · 云

黄昏。窗。一只手把一张旧纸展开在桌上。
纸上是六行诗，前四行墨色已旧；第五行只有一个「其」字，旁边洇开一团墨。
他抬头。窗外云霞翻涌，远山起雾。
镜头穿过云——

**视觉动作**：窗棂、纸纤维、墨迹、手、云影在纸上移动。

### 0:30–1:15 晚年 · 灯（倒叙第一站：她的结尾）

道姑在灯下写诗。纸上已有四行。
她写第五行「其实我只是爱上了峨眉山上的云和霞」，写到「霞」之前停住。
笔悬着。一滴墨落下去，洇开——**就是现在那张纸上的一团墨**。
她搁笔，看向窗外。窗外也是云霞。

**道姑装扮**：道髻、木簪、深墨道袍，领口一线雪青。不剃度。

### 1:15–2:00 出家 · 剑（第二站）

峨眉，晨课。她教弟子，说话不出声。
剑挂上墙，再没取下来。
两枚金针放进经卷夹层——她始终没有许愿。
雪夜，断墙，剑插在雪里，鞘上三道火燎痕：**父母在城破前铸的，不是他留的信物。**
（全片唯一倒叙中的倒叙，一句解释都没有。）

### 2:00–2:50 寻 · 判词（第三站）

一个渡口接一个渡口，每个都像风陵渡。驴、剑、行囊。
茶楼说书人的声音（画外）：「那郭襄女侠，为杨过大侠终身不嫁……」
街边童谣（孩子的声音，跑调）：「峨眉有个郭女侠，等郎等到白了发……」
传抄的纸页，越摞越高。
她在一处茶棚想开口，锣声响起，没人听。她低头喝完那碗茶。
渡口有人落水——她把第一枚金针拍进那人胸口。救人之后，看着掌心剩下的两枚，很久。

**观众在这里先听见判词，再往回看见她怎么走到那一步。**

> **语气铁律：判词不是反讽，是善意的误读。**
> 说书人讲的是「佳话」，带着敬意，讲到动情处会停一停、叹一口气；孩子唱得天真，不知道自己在唱一个女人的一生；抄书的人工工整整，把它当成美谈。
> 没有人恶意，没有人嘲笑——**全世界都在温柔地替她解释，而她无法反驳**。这比嘲讽痛得多。

### 2:50–3:40 十六岁 · 火（终点，全片最亮）

风陵渡客栈，火塘边一圈人的剪影，她坐最外圈只听。第一次听见「神雕侠」——眼里有一点火光。
她的掌心摊开，三枚金针。赠予者不入画。
生日那夜，满城火光冲天，她仰头，以为那是为她放的烟花。
字幕后落：**满城烟火，本是军情。**
华山之巅，他转身走进云海，没有回头。她站着，没有追。

### 3:40–4:00 现在 · 霞

回到窗边。云霞与十六岁那夜的漫天火光，叠在同一帧上。
镜头落回那张纸：第五行、第六行已经完整——墨迹新鲜，像刚写完。
最后一行：**像极了十六岁那年的烟花。**

他合上纸。窗外，天色正好。

## 两条线

**现在线（他）**：只有手、窗、茶、纸、天光。不露脸、不出现任何现代物品。
**记忆线（她）**：倒叙，晚年 → 出家 → 寻 → 十六岁。

**两线之间只有一样东西连通：云。**

## 诗六行的位置

| 行 | 落在 | 说明 |
|---|---|---|
| 1 我走过山时，山不说话 | 现在 · 云 | 他展开纸时读到，窗外远山即此句 |
| 2 我路过海时，海不说话 | 现在 · 云 → 入梦 | 云海即「海」 |
| 3 小毛驴滴滴答答 | 寻 · 判词 | 驴蹄四拍，与判词的声音叠在一起 |
| 4 大家都说我因为爱着杨过大侠 | 寻 · 判词 | **判词先听见，真相后看见** |
| 5 其实我只是爱上了峨眉山上的云和霞 | 晚年 · 灯 | 写不下去的那一行 |
| 6 像极了十六岁那年的烟花 | 现在 · 霞 | 全片最后一句 |

## 与 v2 的差异

| 项 | v2 | v3 |
|---|---|---|
| 时间 | 顺序（十六岁→出家） | **倒叙**（晚年→出家→寻→十六岁） |
| 视角 | 她在写诗 | **他在读她的诗**；现在线只见手与窗 |
| 入口 | 纸 | **云霞**（窗外的天） |
| 判词 | 中段出现 | **更早出现**，反讽先立起来 |
| 亮度 | 前亮后暗 | **一路递增**：灯→雪→火→烟花→晚霞 |
| 结尾 | 她写完 | **纸上墨迹完整**（他终于读懂），他合上纸 |

## 待定

- 人物设定：郭襄的武侠／动漫风格模型待定；现在线的「他」的形象待定。
