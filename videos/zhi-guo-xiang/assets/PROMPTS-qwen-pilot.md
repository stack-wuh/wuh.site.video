## P1 · 他 · 礁石上读纸（实拍质感）

> 这是全片地基。他不是画，他是真人。上一版把他画成了动漫侧脸，全错。

```
纪实摄影，黄昏海边，35mm 镜头，浅景深，自然光。一名三十岁左右的中国男子背对镜头坐在黑色礁石上，面朝大海：肩背略宽，短发，一副细框眼镜的深色镜腿在耳侧隐约可见，浅米色棉质短袖衬衫，深色直筒长裤，一只深蓝色斜挎帆布包横在腰侧；他膝上摊着一张泛黄的旧纸，右手手掌压住纸边，左手撑在石上。太阳贴着海平线，逆光，人物轮廓有一层暖金色边光，从背后完全看不到脸。海面只有细碎的暖金反光，远处云霞很低，云层缓慢翻涌。画面安静，只有他一个人，没有船，没有建筑。画面里没有任何文字。
```

**验收**：① 是背影、绝对看不见脸 ② 衬衫/眼镜腿/蓝包三件细节在 ③ 纸真的摊在膝上、不是飘着 ④ 光是从海那面来的逆光，不是正面打光。

## P2 · 道姑 · 灯下停笔（绢本）

> 参考图：四十岁道姑全身像。上半身入画即可，**侧后方**，不给正脸。

```
中国宋代绢本设色绘画，工笔写实，笔法细腻，色彩雅淡沉着，绢面有细微纹理与岁月感，构图留白，画面静谧像一帧电影。南宋禅房内，一位四十岁的道姑坐在木案前，侧后方视角，看不见正脸：头发乌黑绾成道髻，插一支木簪；身穿深墨色宽袖道袍，领口露出一线雪青内衬；肩背笔直，身形清瘦挺拔。她右手执笔，笔尖悬在纸上方，还没有落下。案上摊着一张空白的旧纸，纸面没有任何字迹、没有任何墨痕。案角一盏陶制小油灯，火苗很小，暖光只照亮案面一小圈，其余沉在暗里。窗外是淡淡的黄昏云霞。画面里只有她一个人。画面中不要出现任何文字、题跋、印章、落款。
```

**验收**：① 侧后，看不到五官 ② 道髻 + 木簪 + 深墨道袍 + 一线雪青领 ③ 纸上干干净净 ④ 灯是陶制的油灯，不是玻璃罩台灯。

## P3 · 十六岁 · 火塘外圈（绢本）

> 参考图：十六岁服饰三视图。重点是**一圈人的背影**和**她与人群的距离**。

```
中国宋代绢本设色绘画，工笔写实，笔法细腻，色彩沉着，绢面有细微纹理，画面静谧像一帧电影。南宋客栈的夜晚，屋子中央一口火塘燃着低矮的暖黄色火焰，一圈人围着火塘席地而坐，全部是深墨色的背影剪影，只能看见肩背与后脑，没有脸、没有表情。画面最外圈靠左前方，一名十六岁的少女独自坐着，同样是背影：双鬟垂在耳侧系青色丝绦，肩上披灰紫色斗篷，身形娇小，和人群之间空出一点距离。木梁与廊柱沉在暗处，火光只照亮火塘周围一小圈，其余是浓重的暗。画面里没有任何文字。
```

**验收**：① 所有人的脸都不可见 ② 能一眼找到她——她在最外圈、单独一个、比周围人小 ③ 火是低矮的火塘，不是熊熊篝火 ④ 暗部要够暗。

## P4 · 渡口 · 驴与剑（绢本）

> 参考图：十六岁服饰，改成二十岁的风尘气。这一镜同时要交代驴、剑、行囊。

```
中国宋代绢本设色绘画，工笔写实，笔法细腻，色彩雅淡沉着，构图留白，画面静谧像一帧电影。黄昏的渡口土路，一头青灰色毛驴驮着行囊向前走，驴背横挂一柄深墨色长鞘的直剑，鞘口垂下两股纸灰色的剑穗；驴的右侧走着一名二十岁的青年女子，完全背对观者：头发绾成单髻、裹一块褪色的青布巾，身穿灰紫色短褐与长裙，小腿绑腿，背一只行囊，一手牵着缰绳。前景芦苇低垂，远处是土黄色的暮色与一条河，河边泊着一条小船。画面里没有任何文字。
```

**验收**：① 剑横挂在驴背上，不是她背在身上 ② 她的背对着我们 ③ 驴是驴，不是马 ④ 暮色土黄，不要蓝紫黄昏。

## P5 · 杨过 · 独臂背影（绢本）

> 全片最重要的一次出场。**永远不给正脸。**

```
中国宋代绢本设色绘画，工笔写实，笔法细腻，色彩沉着，构图留白，画面静谧像一帧电影。夜晚的客栈门外，一个高瘦的男子背对观者站着，看不见脸：深墨色长袍，长发半束，右侧衣袖空垂、里面没有手臂，肩背笔直。他前方是扑面而来的暖橙色火光，整个人成为逆光的黑色剪影，只有轮廓被火照亮。天空极淡处有一只大雕的影子掠过。画面里没有别人。画面中不要出现任何文字。
```

**验收**：① 右袖是**空**的，垂下去，一眼能看出少一条胳膊 ② 完全逆光，脸是黑的 ③ 长袍深墨，不是白袍 ④ 大雕只在天空极淡处，不能是只大鸟站在旁边。

## P6 · 华山 · 云海小影（绢本）

> 全片最后一镜。他走进雾里。**留白要大，人影要小。**

```
中国宋代绢本设色绘画，工笔写实，笔法细腻，色彩雅淡沉着，构图大片留白，画面静谧像一帧电影。高山之巅的云海，白色云雾在脚下缓慢翻涌，远处峰峦只剩极淡的墨色轮廓；云海边缘站着一个很小的深墨色人影，完全背对观者，正走进前方的雾里。画面绝大部分是云与雾的空茫，人影只占很小一块，越淡越好。画面里没有任何文字。
```

**验收**：① 人影占画面不到 1/20 ② 云是留白，不是棉花糖 ③ 没有太阳、没有晚霞——这里是雾，不是黄昏。
