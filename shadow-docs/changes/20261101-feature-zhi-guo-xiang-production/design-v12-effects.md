## 一、先定"动画片级"是什么意思（验收口径）

一条可执行的判据，避免又变成"再多调两版"：

| # | 判据 | 反面（v11 现状） |
|---|---|---|
| 1 | **任意一帧单独截出来，读作一张手绘水墨**，不是"照片上叠了图层" | 代码叠的剪影/袖子像贴纸 |
| 2 | **镜头运动有真实透视**：推拉摇移时前后景以不同速度位移、有视差、有景深 | 整张图一起缩放（=数字缩放，不是运镜） |
| 3 | **光是真的**：火/烟花/灯照亮周围物体，受光面与背光面有明暗转折，影子随光走 | 全屏叠一层暖色 / 一个径向光斑 |
| 4 | **动的是"形"，不是"位置"**：火在卷、烟在翻、墨边在长、雪片有大小与景深 | CSS 位移+透明度补间 |
| 5 | **帧率节奏**：主体动作 on 2s/3s（12–15fps 的作画感），镜头与特效可以逐帧 | 全部 30fps 线性插值（=PPT） |

只有 1–5 全过，才算"动画片"。**3D 只是手段**：它一次性解决 2、3、5，并让 1、4 变得可做。

## 二、技术选型（已实测）

**结论：three.js + @react-three/fiber，跑在 Remotion 里，自己写 NPR 水墨着色器。**

| 候选 | 判定 | 理由 |
|---|---|---|
| **three.js in Remotion** | ✅ **采用** | 实测本机 headless Chrome 走 ANGLE/Metal 到 Intel Iris 655，WebGL 着色器正常出图；帧由 Remotion 逐帧驱动 → 确定性、可与现有镜头/转场/字幕同管线；着色器完全可控 |
| Blender + EEVEE/Cycles | ⚠️ 备选 | 本机没装；Intel Iris 无 CUDA，Cycles 只能 CPU 8 核（1080p 简单场景 5–15s/帧），EEVEE 可用但要用 bpy 全脚本化建模；迭代速度不如 WebGL 实时 |
| AI 视频模型（i2v/v2v） | ⚠️ 只作补丁 | `bl video generate` 可用，但角色/手会崩，只适合空镜（云、雾、雪、烟花尾迹）——可作为 3D 渲染后的"再手绘化"一层 |

依赖：`three`、`@react-three/fiber`、`@remotion/three`（都还没装，试点前加）。**渲染开关**：`chromiumOptions: { gl: 'angle' }`（Remotion 侧），并用现有 `disableSharedMemoryCapture` 防鬼帧。

## 三、NPR 水墨怎么实现（四个技术支点）

### 3.1 几何：3D 场景 + 2.5D 人物

- **环境全 3D**：地形（AI 出的高度图 → 位移网格）、城墙/城楼（盒体 + 细分 + 噪声）、茶馆（室内盒体 + 桌凳）、树/芦苇（曲线 + billboard 面片）。
- **人物不建模，用"卡片 + 剪影体"**：这是关键取舍。本片规矩本来就是「杨过永远背影、郭襄只给三次脸、其余是剪影」——
  - 正面/侧面表现：AI 生成的水彩人物卡（带 alpha），作为**带厚度的 billboard** 放在 3D 场景里，受同一套光照与雾影响；
  - 需要"转身/抬手"时：把动作拆成 **2–3 张替换件**（背→侧、垂手→抬手），用位移+扭曲补间 + 布料后的次级摆动，而不是骨骼；
  - 远景（<10% 画高）：直接用剪影深度体（有法线、有描边、有墨材质），可被雾与光正确作用于。
- **理由**：给人物做骨骼绑定是这条管线里唯一"必翻车"的部分（本机没人手、AI 出不了绑定），而 2.5D 卡片在 3D 场景里已经能给出 90% 的"运镜真实感"。

### 3.2 Ink Shader（水墨着色器，整条管线的灵魂）

在片元着色器里按序做五件事：

1. **色调分层（tone banding）**：把 Lambert+环境光压成 3–4 阶（纸白 0.86 / 淡墨 0.55 / 中墨 0.32 / 浓墨 0.18），阶与阶之间用 smoothstep 留 2–4px 过渡——这是"墨分五色"的算法版。
2. **matcap 材质**：用 AI 生成的**水墨球**（一张 512×512 的水墨渲染球面图，含浓淡、飞白、渗化）做 matcap 采样，替代纯色明暗——这一步决定了"像画的"还是"像塑料的"。
3. **笔触扰动**：把 UV 用 2–3 层 fbm 噪声扰动（振幅 3–8px，随时间缓慢漂移），让色阶边界变成笔触边而不是等值线。
4. **描边**：法线 + 深度 Sobel，取 1.5–2.5px 粗细，颜色不是纯黑而是 `colors.ink`（#2b2620）乘纸色；**粗细随景深变**（远处细、近处粗）——这是水墨的"远近"。
5. **纸纹与吸水性**：一层纸纤维噪声 multiply + 边缘略深的"洇"（用屏幕空间模糊的墨量做边缘累积）。

### 3.3 体积与粒子

- **雾**：屏幕空间一层 raymarch（16–24 步、3D fbm），密度由地形高度衰减——雪脊、河谷、茶馆内茶烟都用它，能真正"吃"掉人物下半身（S21 的雾就是这么来的，不是贴图）。
- **雪/灰/烬**：GPU 点精灵（每粒有景深 → 近大远小、近快远慢、近处虚焦），风场用一个全局向量 + 噪声扰动。
- **烟花**：**不做真实爆轰模拟**。用「2D 团块 card（AI 生成的水彩团块 6–8 张）+ additive 粒子尾迹 + 照亮场景的一次性点光」——加上 3.3 的雾，观感就是"烟花在城上炸开"。
- **墨滴/洇开**：屏幕空间"墨量场"（一张 R 通道贴图随时间扩张）驱动 diffuse 吸收——S34 的墨吃掉那个字，用这个做才像纸吸墨。

### 3.4 合成与节奏

- 3D 渲染出图后，Remotion 层再做：**多级阈值墨晕**（高墨量区域做 2 段 blur + 阈值回贴）、纸纹 multiply、轻微暗角、<2px 的 RGB 偏移（模拟纸张与镜头）。
- **帧率节奏**：主体动作按 on 3s（10fps）采样、运镜与雾按 30fps；在 Shader 里用 `frame - frame%3` 取值即可，不需要改时间轴。

## 四、关键镜头方案（只做这 6 段）

| 镜 | 现状问题 | v12 做法 | AI 资产 | 风险 |
|---|---|---|---|---|
| **S11/S12 烟花** | 团块"贴"在城上，不像炸开 | 3D 城墙/城楼/屋脊 + 真点光 + 8 朵团块 card + 体积雾 + 屋脊受光 | 水彩烟花团块 ×6、城砖/瓦纹 ×2、夜空纸纹 | 爆点亮度与过曝控制 |
| **S16 十六年** | 季节靠调色，像滤镜 | 同一条 3D 土路地形走三拍季节（雪层/植被/光角度真变），毛驴与郭襄为远景剪影体 | 土路材质、芦苇 billboard、雪层 matcap | 季节切换节奏（要"跳过年份"的硬切感） |
| **S19 雪山独行** | 人小但平面，雪像噪点 | 3D 雪脊地形 + 真景深薄雾 + GPU 雪 + 她为剪影体走远（视差真实） | 雪坡材质、枯枝 billboard | 白场控制（水墨的白很容易糊） |
| **S20/S24 茶馆** | 静态画 + 假茶烟 | 3D 室内盒体 + 窗棂投影（真光斑）+ 体积茶烟 + 人物卡片群 + 醒木/锣的画面回执 | 木构架材质、人物卡片 ×4、茶碗 ×1 | 室内光难（窗光泄露） |
| **S21 揭面** | 两坨黑色/袖子像布 | 3D 雪坡 + 体积雾 + 两个人物卡片（他背对她 3/4 侧后）+ 手部独立卡片做"抬到面具" + 金针为真 3D 细柱（有高光） | 他背影视点卡、她侧后卡、手部 3 张替换件 | **最难的一镜**，需 2–3 轮迭代 |
| **S34 墨滴** | multiply 只盖住七成 | 纸面为平面 + 墨量场驱动吸收（真"吃字"）+ 纸纤维 | 纸纹、湿墨边 | 与 S33 同机位一致性 |

其余 31 镜**不重做**：它们都是"静帧 + 微动"，在动画片语言里本来就成立（空镜、特写），重做反而破坏节奏。

## 五、试点（先做 2 段，合计 12 秒，1 天内）

## 六、成本与排期（本机实测口径）

- 渲染速度：WebGL 逐帧截图，1080p、简单场景预估 **0.3–1.5s/帧**（Intel Iris 655，需实测校准）；210f 一镜 ≈ 1–5 分钟/遍，可迭代 10 遍以上。
- 试点 P1+P2（约 400f）+ shader 开发：**1 天**（含 3 轮修改）。
- 6 段关键镜（约 1100f）+ 资产整合：**2–3 天**（不含剧本/旁白重做）。
- AI 资产：约 40–60 次生图（材质、卡片、团块、纸纹），沿用现有 `bl image` 口径。

## 七、明确不做的事（避免又跑偏）

1. **不做角色全身骨骼动画**——人物用 2.5D 卡片 + 2–3 张替换件，走/转身靠位移与扭曲。
2. **不做真流体/真爆轰**——雾用屏幕空间 raymarch，烟花用 card + 粒子。
3. **不重做全片 38 镜**——只做 §四 的 6 段。
4. **不在这轮动剧本与旁白**（用户已指出那两处也有问题，另开一轮）。
5. 不改现有 `shots-manifest` 结构：3D 镜头仍是一个 `sNN.tsx`，内部换成 `<Scene3D>`，时长与帧号不动。
