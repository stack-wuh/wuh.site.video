## 零 · 故事事实（已按原著更正）

初稿 §零 写的「三个愿望都当着杨过的面用、第三个求他与小龙女重逢」**不成立**，混了两套东西：

- **对天三愿**（第三十六回生日）第三愿才是「愿杨过与小龙女早日团聚」——**与金针无关**，那是对天许的，不是用针换的。
- **金针**的定义是「我见此金针，如见你面；**托人持针传命**，我也必给你办到」——是**差他办事**，不必见面。第一枚许的是「取下面具，让我瞧瞧你的容貌」。
- 仓内 `videos/preprod-zhi-guo-xiang/assets/materials.md:179` 早就警告过：「三枚金针的具体心愿本库只记『三次心愿』，不逐条展开；如剧本要用，需回原著第三十五回逐句核对。」初稿没读这条，是我的流程失误。

**本片采用的口径（路 B，见 §一）**：她一生只用掉**一枚**，求的是看一眼他的脸；剩下两枚舍不得用，出家时夹进经书。这与仓内既有账目链完全一致（S25 剩两枚 → S29 两枚入经卷 → b11「没烧掉」）。

## 一 · S21 重新设计：求揭面

### 1.1 先解决初稿没发现的时间线冲突

初稿把「第一枚」直接放进 S21，但：

| | 位置 |
|---|---|
| S10 领受三枚金针 | act2 · abs **58–64s** |
| S11–S15 满城烟花 | act3 · 同夜 |
| **S21** | **act4「寻」· abs 126–133s** |

原著第一枚是十六岁那夜当面用的。放在 126s 的「寻」幕里，**S20 落醒木 ↔ S21 用针的「同一时刻」并置同样失效**（初稿与编剧席都以为路 B 能保住这个锚，保不住）。

**修法：把「用针」推迟到她终于找到他的那一刻。**

她领了三枚针，一枚没用。寻访多年（S16–S19），每次都晚三天（b06）。直到某一次她终于赶上——**她把唯一那一枚用掉，只求看一眼他的脸**。剩下两枚，此后再没动过。

这样时间线自洽，而且比原案狠得多：

- **S19「她每次都晚三天」→ S21「这一次她赶上了，用掉唯一的针」→ S22「她没有解释」** —— 三镜成一条完整的因果，「同一时刻」重新成立
- **S25 剩两枚**：不是「还没用」，是**舍不得用** —— 与 S26 拈针「看了很久又放下」（分镜 §109 戏眼正是「舍不得用掉那枚针」）第一次真正呼应
- **S29 两枚入经卷 / b11「没烧掉」**：一个字都不用改

### 1.2 代价：全片视觉铁律必须改写

v9 `script-v9.md:110` 现在写的是：

> **杨过永远不给脸。** 这不是美术限制，是故事——**郭襄自己就没看见**。她只看见一个背影、一只空袖、天上一只雕的影子。

路 B 要求她**求看了、而且看到了**。这条理由必须改：

> **杨过永远不给脸。** 这不是美术限制，是故事——**她拿唯一一次机会换了一张脸，观众仍然不给**。镜头站在她身后，或停在他抬手到面具的那一下。她看见了，我们没有。

这才是「一见杨过误终生」的物理形状：**她看见的那一眼，是全片唯一被允许的一次，而摄影机不借给她。**

### 1.3 画面（S21 保持 210f / act4 / 126–133s 不动）

按导演席的批评重排——初稿 210f 里塞了四个动作、且 §1.4 的光效层根本演不了人物位移：

```
0–45f    她站在雪径尽头，右手举着金针；他背对，不动
45–115f  只演一件事：他抬手，到面具为止（唯一的交接）
115–165f 他转身，持续走出画面（不「停住」——走而不停读起来是仍在离开）
165–210f 45f 给她的手：还举着，针已经不在了
```

**砍掉的两个动作及理由**（采纳导演席）：
- 砍「他微微侧过头」：背影+空袖已说明「是人不给脸」，侧头是重复表达，且它正是「不能到鼻梁」这条红线的风险源
- 砍「停住」：省 15–20f 给末段空手，且「仍在离开」比「停下」更对

**实现路径**：`components/Figure.tsx:78` 的 **`YangGuoFigure` 已经写好**（只给背影、独臂、空袖、半束长发），**被 0 个镜头引用**。这场戏的「背影」由它承担，不依赖模型画空袖——美术席已判 `p-giving` 三张全废、空袖画不出来，这条是唯一的出路。

底图改用**无人物的雪径尽头**（可复用 `p-footprints` 的远端，或新出一张不带人的），人物两层全由代码剪影给。

### 1.4 音画：初稿把 b08 认错了位置（FE-1）

初稿说「改 b08 来补 S21」——**b08 不在 S21**。实测：

| | 绝对秒 | S21 上播什么 |

S21 全程 **99% 有人声**。而 b06 讲的是「错过」，改戏后这 2.2s 画面演的是「她终于赶上、用掉唯一的针」——**语义正好相反**，会把这场戏讲歪。

**动作**：

## 二 · 手与针：接线，不是重画

### 2.1 美术席判定（九张候选）

| 资产 | 判定 | 硬伤 |

| `p-giving` | **三张全废** | 空袖三张都不可辨（都画成双手笼袖）；cand-3 还越「不给脸」红线（露到嘴唇）且递针方向反了；三张全部裁头 |

**cand-3 的保留风险**（美术席提出，我复核同意）：它只修了「手型」，没修「线条」。三张都用硬墨勾线+肉色平涂，轮廓线粗细和被否的 `p-palm.jpg` 一样；而全片人物与景是淡墨渲染、几乎不勾死边。**用户原话「太粗糙」有两层，可能因同一理由再被否一次。**

### 2.2 参考图方向初稿搞反了

初稿计划用 `p-eyefire` 当参考出 S26 侧脸。但 `p-eyefire` 是 **3/4 正面**，拿正面生成纯侧面，模型只能猜鼻梁——这正是三张各画一个鼻子的原因。

**正确**：identity 参考 `p-eyefire` + **角度参考 `p-her-up`**（同一张脸的侧仰面，下颌/唇形/鼻尖/耳形已在侧面解过一次），两张一起传。

### 2.3 针位：S25 必须是 S10 的子集

初稿 §2.4「针的落点直接复用 S10 的数值」——我按 `Needles.tsx` 公式实算，**现在不是子集**：

```
S10  count=3 origin=[820,600] spread=70 → y = 530 / 600 / 670
S25  count=2 origin=[800,640] spread=62 → y = 609 / 671   ← 第一根差 9px
```

**改法**：S25 严格取 S10 三槽中的两个，`origin/spread/tilt` 三值与 S10 完全一致、只 drop 一个 `i`。零成本，收益最大——「同一只手少了一枚针」这句话到这才成立。

### 2.4 两镜的推镜必须对齐

`S10 zoom=[1.04,1.1]`、`S25 zoom=[1.0,1.06]` —— 两个不同推镜会让同一张底图在两次出现里取景不同，「同一只手」的确认感被削弱。两镜对齐到同一区间。

### 2.5 真实工作量是「接线」

导演席查 import，**五个已写好、被 0 镜引用**：`Figure.tsx`（`YangGuoFigure`/`XiangFigure`/`CrowdFigure`/`DiscipleFigure`）、`Objects.tsx`（`Sword`/`Donkey`/`Ferry`/`Scripture`/`Gate`）、`CameraRig.tsx`、`ArtBase.tsx`、`AscendScene.tsx`。

## 三 · 转场

### 3.1 架构结论（初稿 FE-2，最重的一条）

**初稿的实现路径产出 0 像素。** 已复核确认：

- `routes.tsx:14-19` 镜级 comp = `<ShotShell><Shot /></ShotShell>`，**不含 `ZhiGuoXiang`、不含 `FilmShell`、不含兄弟镜**

**唯一可行解：镜内占用，manifest 时长一律不改。**

- 入场遮罩吃本镜**前 24f**、出场遮罩吃本镜**后 24f**（48f 转场 = 相邻两镜各出 24f）
- `durationFrames` / `startFrame` 一个字节都不动 → 总时长仍 7050f，人声/BGM 的绝对秒全部不变，`vo-script-v5.md` 与 `bgm-ai-yi-map.md` 的对位表继续成立
- 落点选 **`components/ShotShell.tsx`**：改 1 处，`routes.tsx` 镜级 comp 与 `ZhiGuoXiang.tsx` 两条路径同时生效，`useCurrentFrame()` 在两边都是镜内局部帧（playbook「帧号双重偏移」条已确认）——**初稿想要的「38 个镜头组件一个不碰」仍然成立**
- 代价（导演席实算）：210f 镜 → 162f（−22.9%）、180f → 132f（−26.7%）、150f → 102f（−32%）
- **必须连带重排字幕**：现 14 条字幕里 13 条的 `start` 普遍 12–20f，会撞进遮罩。安全窗：150f=`[48,102]`、180f=`[48,132]`、210f=`[48,162]`

### 3.2 四类转场 → 三类（放弃 D）

**D 残余特写在镜内占用下做不到**（要求上一镜末帧的裁切出现在下一镜底下，跨镜）。放弃它。若将来一定要，得单独存一张末帧裁切图当资产，但那会破坏 `render-film.mjs:148` 的缓存哈希（只哈希 composition id + durationFrames + fps，不哈希内容），单镜重跑会拿旧图。

### 3.3 密度：按用户决定大幅收

初稿按自己的规则实算是 **37 界里 35 界非硬切（94.6%）、转场覆盖 1632f = 全片 23%**，正好盖在剧本 §七 明写的三处有意留白（11–23s / 144–151s / 157–163s）上。**已定：大幅收。**

| 类型 | 处数 | 帧 | 用在哪 |
|---|---|---|---|
| **纸翻** | **3** | 36f | s02→s03（读纸→渡口）、s26→s27（**二十四年**）、s35→s36（很多年后）——都是真实时间/空间大跳 |
| **飞白** | **2** | 20f | s16→s17、s22→s23（时间压缩） |

### 3.5 限制已解除（保留初稿结论，并换一条更硬的实证）

### 3.6 不加音效

采纳声效席，一条都不加。三条依据：
