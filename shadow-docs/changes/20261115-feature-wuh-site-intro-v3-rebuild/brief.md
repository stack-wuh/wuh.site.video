# wuh.site 介绍片 v3 重做：正式制作（56 镜亮色信息密度 · CI 出片）

## 动机

前期 change（`20261114-feature-wuh-site-intro-v3-redesign`）已交付并定稿：素材库 v4（2026-11-14）、风格锚点 v2（亮色信息密度 / 站点同源色板）、剧本 v2《七年，一座站》（3:21 / 六幕 + 冷开场 / 无配音，用户四项拍板通过）、分镜 v2（56 镜 / 正片 5700f / import 全绿）、动效规范 v2（令牌 + 全镜覆盖矩阵）。本 change 把它落成成片。

## 复杂度评级

- **评级:** L
- **理由:** ① 契约变更：新视觉系统落地（motion-tokens v2 + 组件层 + 56 镜一镜一文件）；② 触及面：videos/wuh-site-intro-v3 全量（组件/令牌/数据/镜文件/装配/路由）+ public 配乐 + CI；③ 可发现性：视觉质量无机器断言，靠 3 镜风格样片门 + 全片抽帧走查；帧数/typecheck/镜文件存在性可机检。
- **期望验证深度:** runtime（CI 出片 + 三重终验 + 抽帧走查）
- **取证策略:** observation（帧数/typecheck/check 为 assert；美学走用户门）

## 领域模型

- **限界上下文:** video-materials — 正式制作（wuh-site-intro-v3 单元）。上游：前期五件套定稿（script/storyboard/motion-spec/style-anchor，另一 change）；下游：CI render-film 出片 + 用户验收。反腐边界：本 change 不改叙事层（帧窗/文案/幕界以 manifest 为真源），只做视觉与声音执行。
- **统一语言增量:**
  - **FILM_COLORS**：亮色色板唯一合法源（纸/墨/朱/金/泥金，站点 wine 亮色令牌同源）。
  - **数据件**：一切画面由真实数据/文本绘制的矢量件，零网站截图。
  - **样片门**：3 镜风格样片 CI 出图过用户定稿后才铺全量。
  - **帧时表达式**：镜内 `local = useCurrentFrame()`，动画只用局部帧；对音点 = 镜内帧，与 20f 拍网格对齐。
- **聚合与不变量:**
  - `INV-1 时间轴真源`：Σ durationFrames = 5700，manifest 不改；观察点：`node scripts/shots.mjs check --unit wuh-site-intro-v3` 无帧数类报错。
  - `INV-2 镜级契约`：一镜一文件、局部帧 0 起、自包含、禁跨镜 import、禁 `<Audio>`、确定性（random(seed)，禁 Date.now/Math.random）；观察点：typecheck 0 错 + 走查 + 渲染 nb_frames = durationFrames。
  - `INV-3 零截图`：全片不引用 `public/wuh-site-intro-v3/site/` 任何截图；观察点：`grep -r "intro-v3/site" videos/wuh-site-intro-v3` 为空。
  - `INV-4 色板唯一源`：镜文件与组件禁 inline 色值/字体字面量，一律 FILM_COLORS / FONTS 令牌；观察点：走查 + oxlint。
  - `INV-5 样片门`：3 镜样片未过用户定稿不得铺全量；观察点：brief 记录。
  - `INV-6 出片三重终验`：ffprobe nb_frames=6030、video/audio 两路时长一致、分段音量覆盖片尾（有 BGM 后）；观察点：CI assemble 输出 + 本机 ffprobe。
- **领域事件:** 视觉基座绿 → 样片 CI 出图 → 用户定稿门 → 全量 56 镜 → 全片 CI 渲染 → 用户评审 → BGM 终混交付。

## 决策

- **选型:** 沿用两段式第二段标准管线：motion-tokens+组件层 → 3 镜样片门 → 4 批并行实装 56 镜 → 装配（FilmShell 150+5700+180=6030）→ CI 全片渲染 → 抽帧预览 → BGM 终混。零图片资产，全部 Remotion 矢量 + `data.ts`（由 `.tmp/materials-v4.json` 固化）。
- **对比方案:** 逐镜串行实装（弃：56 镜墙钟过长）；先全量后看样片（弃：方向错误会烧 56 镜）；引入 AI 首帧图（弃：用户令零截图/内容当主角，且增资产复杂度）。
- **理由:** 样片门用最小成本锁风格；并行批次按幕切分、零共享状态（一镜一文件），符合 shot-spec 缓存与返工粒度。
